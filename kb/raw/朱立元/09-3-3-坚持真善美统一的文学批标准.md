# 3. 3.坚持真善美统一的文学批标准

9. 3. 3.坚持真善美统一的文学批标准
文学作品的内容与形式应当尽善尽美地结合起来，这既是葛兰西对于内容
与形式关系的基本看法，又成为他所主张的马克思主义文学批评的基本标准。他
深刻地指出：“实践哲学③的文学批评，必须以鲜明的、炽热的感情，甚至冷嘲热
讽的形式，把争取新文化的斗争，即争取新的人道主义的斗争，对道德、情感和世
界观的批评，同审美批评或纯粹的艺术批评和谐地冶于一炉。①葛兰西通过对
意大利文艺批评的历史经验的总结，特别是通过对克罗齐的批评与德·桑克蒂
斯的批评加以比较，进一步深化了他所主张的文学批评应熔道德、情感批评与审
美批评于一炉的观点。他认为，桑克蒂斯的批评是种把道德、情感的批评与美
学的或纯粹艺术的批评融为-体的战斗的批评，而克罗齐的批评则把形式等同
于内容.割裂了文艺与祛会生活的联系，只是一种冷荐冰霜的美学批评
葛兰西认为，文学批评应当结合具体的历史条件来分析、评价作品，他对乌

马舍雷和戈德曼都是法国的西方冯克思主义文学理论家，而宜两人的文学
理论都在一定程度上受到了结构主义的影响，当然从总体上说还是有着明显区
