# 多利莫尔（Jonathan Dollimore）

## 生平与学术背景

- **国别 / 时代**：英国学者，20世纪后半叶
- **学术身份**：英国"**文化唯物主义**"（cultural materialism）的代表人物；与艾伦·辛菲尔德（Alan Sinfield）合编《政治的莎士比亚》（Political Shakespeare, 1985），成为文化唯物主义的纲领性文献
- **理论定位**：文化唯物主义与美国新历史主义学术宗旨、文学理论意向和政治话语基本原则相当接近，仅因地域文化氛围之别存在微妙差异；多利莫尔长于文艺复兴戏剧的政治功能分析，尤其莎士比亚研究

## 核心文论贡献

### 一、文化唯物主义四要素

在《政治的莎士比亚》序言中，多利莫尔提出文化唯物主义的四个构成要素：

1. **历史的发展脉络**：任何文本都必须置于其产生的具体历史语境中考察
2. **理论的方法意向**：自觉运用结构主义、后结构主义、西方马克思主义等当代理论
3. **政治的权力参与**：批评本身是政治实践，"一切历史都是当代史"在文化唯物主义研究中得到鲜明体现
4. **文本的分析框架**：以文本为权力斗争的场域进行意识形态分析

"文化唯物主义"一词借自[[figures/雷蒙德·威廉斯]]（Raymond Williams），汇集文化研究中历史、社会、女权主义、西方马克思主义、结构主义和后结构主义等多种理论（尤其是阿尔都塞、马歇雷、[[figures/葛兰西]]和[[figures/福柯]]）。

### 二、文艺复兴的"过渡性"

- 文艺复兴介于中世纪与现代之间：中世纪基督教将人视为从上帝获得本质的完整统一体，启蒙人本主义坚持确立作为个体的人
- 文艺复兴是**怀疑的时代**，是两种意识形态矛盾冲突的漩涡中心：人的本质不再稳固，"人"开始成为问题
- "一切历史都是当代史"：透过文艺复兴发现的根本问题（权力、意识形态、主体建构）正好印证20世纪的问题——批评的政治性正在于此

### 三、戏剧政治三功能：巩固、颠覆、遏制

多利莫尔将文艺复兴戏剧的政治功能归纳为三个核心概念：

| 功能 | 英文 | 含义 |
|---|---|---|
| **巩固** | consolidation | 戏剧在现实秩序中播撒意识形态，把社会等级说成神的意志或自然秩序，使现存秩序合法化 |
| **颠覆** | subversion | 对家长制压迫、女性被压抑、社会秩序强迫接受观念的反抗；戏剧释放对权威的质疑能量 |
| **遏制** | containment | 权力为自我巩固而预先设计破坏——颠覆性力量最终被重新纳入秩序、收编招安 |

著名论断："**明显对权力构成威胁的，正是权力自己**"（the threat to power is built into power itself）——颠覆性声音不是权力的外部敌人，而是权力自身运作的产物；权力通过生产并表演自己的反面来确证自身。

### 四、批评个案：《查理二世》

- 莎士比亚《查理二世》露天演出时，"戏剧幻想"与"现实本身"界限模糊：观众在剧场中目睹国王被废黜的场景，伊丽莎白一世感到影射的就是她——悲剧意义进入现实权力运作层面
- 戏剧舞台成为君主政治合法性被公开质询的场所；演出事件本身就是政治事件
- 文化三层次分析框架：**主流文化 / 次要文化 / 边缘文化**——戏剧在三者之间流通、协商，边缘与次要文化对主流文化构成持续的压力和改写

## 主要著作

- 与辛菲尔德合编《政治的莎士比亚：文化唯物主义论文集》（Political Shakespeare: Essays in Cultural Materialism, 1985）
- 《激进的悲剧：莎士比亚及其同时代戏剧中的宗教、意识形态与权力》（Radical Tragedy, 1984）
- 《性异议：奥古斯丁到王尔德、弗洛伊德》（Sexual Dissidence, 1991）
- 《欲望：性的谱系》（Desire: A Memoir, 2017）

## 在文论史中的位置

- 所属流派：英国文化唯物主义（与美国[[movements/新历史主义]]平行呼应）
- 理论资源：[[figures/雷蒙德·威廉斯]]文化唯物主义命名、阿尔都塞意识形态理论、[[figures/葛兰西]]领导权、[[figures/福柯]]权力分析、马歇雷文学生产理论
- 与[[figures/格林布拉特]]（文化诗学）、[[figures/蒙特洛斯]]（文本历史性/历史文本性）构成新历史主义/文化唯物主义的英美两翼
- "巩固—颠覆—遏制"与蒙特洛斯"遏制与颠覆"命题直接呼应，成为新历史主义分析权力—文学关系的标准工具
- 后启：文艺复兴文化政治研究、莎士比亚政治批评、酷儿理论（多利莫尔后期转向性异议研究）
