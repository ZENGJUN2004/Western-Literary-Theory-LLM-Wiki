# 格雷马斯（Algirdas Greimas, 1917-1992）

## 生平与学术背景

- **国别 / 时代**：立陶宛裔法国符号学家、结构主义叙事学理论家，1917—1992
- **学术身份**：法国结构主义文论的"后四子"之一（与[[figures/巴尔特]]、[[figures/托多洛夫]]、勃瑞蒙并列） [[@朱立元#ch11]]；列维-斯特劳斯、阿尔都塞和拉康属"前四子"
- **学术起点**：从语义学研究开始其叙事学研究——"法国另一位结构主义文论家格雷马斯（1917—1993）是从语义学研究开始其叙事学研究的" [[@马新国#ch18]]
- **方法论基础**：直接引入[[figures/索绪尔]]语言学理论，着力寻找故事叙述的"词法"和"句法"因素，试图通过这种分析，对叙事过程中语义形成的基本结构作出描述 [[@马新国#ch18]]
- **核心信念**："人类世界从本质上说就是意义的世界，'一个没有意义的世界，决不会被称为"人"的世界'"；"似乎只有语言学的位置得天独厚：它更完善，更形式化，可以给其他学科提供经验和方法" [[@马新国#ch18]]
- **代表著作**：《结构语义学》（Sémantique structurale, 1966）

## 核心文论贡献

### 一、行动元模型（六个行动位）

格雷马斯在《结构语义学》（1966）中提出包括六个行动位的模型 [[@朱立元#ch11]]：

| 行动位 | 说明 | 对应普罗普角色 |
|---|---|---|
| 主体（sujet） | 行动者 | 英雄 |
| 客体（objet） | 行动指向的对象 | 被寻找的人 |
| 发者（destinateur） | 派遣或发出任务者 | 发送人 |
| 受者（destinataire） | 接收者 | 被寻者的父亲 |
| 对手（opposant） | 阻挠主体者 | 反角、假英雄 |
| 助者（adjuvant） | 帮助主体者 | 施主、帮助者 |

六个行动位在具体事件中构成两个轴系：①以主体欲望中的客体为中心；②以主体欲望、助者和对手关系为模型 [[@朱立元#ch11]]。

格雷马斯将其与经典哲学图式对照：主体=哲学家，发者=上帝，对手=物质，客体=世界，受者=人类，助者=精神；又指出在马克思主义理论中可改写为：主体=人，发者=历史，对手=资产阶级，客体=无产阶级社会，受者=人类，助者=工人阶级 [[@朱立元#ch11]]。

### 二、[[concepts/符号矩阵]]

格雷马斯最著名的贡献。源于对亚里士多德逻辑学中命题与反命题的诠释，扩充为解释文学作品的矩阵模式 [[@朱立元#ch11]]：

设立一项 X，其对立一方是反 X；在此之外，还有与 X 矛盾但并不一定对立的非 X，以及反 X 的矛盾项即非反 X [[@朱立元#ch11]][[@最新文论教程#ch1]]：

> 一切意义的基本细胞，语言或语言以外的一切"表意"（significance）都是采取这种形式。在这个共时系统中，有八种可能的不同关系。[[@最新文论教程#ch1]]

故事开始时为了解决 X 与反 X 之间的矛盾，但由此派生引发出大量新的逻辑可能性；当所有的可能性都出现了以后，结构便有了封闭的系统，故事也就完成 [[@最新文论教程#ch1]]。

[[figures/杰姆逊]]在《后现代主义与文化理论》中用此矩阵对《聊斋志异·鸽》作过示范性分析，鸟与主人呈友谊关系，与王爷则呈金钱售买关系 [[@朱立元#ch11]]。

### 三、三种叙事结构模式

格雷马斯对普罗普的三十一种功能进一步归纳，提出三种叙事结构模式 [[@马新国#ch18]]：

1. **契约性结构**：叙述契约的建立和中止，禁令和违背禁令等；
2. **表演性结构**：叙述历险、考验、斗争和完成某项任务；
3. **分离性结构**：叙述往返、离别等。

正是在这些模式中，故事的行为者（主语、宾语等）的活动被组合成叙事情节。

### 四、深层结构与意义的"最小单位"

格雷马斯相信叙事作品千差万别但就结构而言有共同性，或称共同的"语法"；他通过对"语义素"差异的分析深入到叙事作品的深层结构 [[@马新国#ch18]]：

> "我们感知差异，借助感知，世界在我们面前'成形'。这'形'仅仅为我们而在。" [[@马新国#ch18]]

[[@最新文论教程#ch1]]以海明威《老人与海》为例，用符号矩阵分析出三层对立：①"人"与"反人"（老人与他人的嘲笑/权力话语）；②"人"与"非人"（老人与鱼）；③"反人"与"非反人"（游客与大海的隔膜）。展示出表面简单人物关系下的复杂多向关系，"导致意义成为一个多维复合体"。

### 五、对普罗普的改造与发展

格雷马斯将普罗普的七个行动范围/七种角色重新组合，划分为三组相互对立的成分 [[@马新国#ch18]]：

| 三组对立 | 一方 | 另方 | 普罗普原型 |
|---|---|---|---|
| 主语—宾语 | 主体 | 宾语 | 英雄—被寻找的人 |
| 发信人—收信人 | 发信人 | 收信人 | 发送人—被寻者的父亲 |
| 帮手—敌手 | 帮手 | 敌手 | 施主+帮助者—反角+假英雄 |

前两组对立是最基本的语义结构；第三组在叙事中起到帮助或阻挠希望和目的得以实现的作用 [[@马新国#ch18]]。

## 关键概念

- [[concepts/符号矩阵]]（carré sémiotique / semiotic square）：以 X / 反 X / 非 X / 非反 X 四项组成的意义基本细胞；八种可能关系
- [[concepts/行动元模型]]（actantial model）：六个行动位（主体/客体/发者/受者/对手/助者）构成的双轴图式
- [[concepts/深层结构]]（deep structure）：叙事作品共同的"语法"；语义素差异所构成的内在形式
- [[concepts/语义素]]（sème）：意义的最小单位；语言结构的基本形态

## 理论局限

[[@马新国#ch18]]指出：格雷马斯比普罗普"更进了一步"——叙事作品确实如语言中具有普遍语法结构的句子一样，成为可以进行语义分析的对象；但他的归纳"也更显得抽象和简单化，因而也更远离纷绘繁复的文学的具体性"。可以说，他也将普罗普研究中包含的、也是结构主义文论弊端之一的模式化倾向向前推进了一步。
