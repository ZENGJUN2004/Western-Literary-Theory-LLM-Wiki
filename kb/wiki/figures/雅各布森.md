# 雅各布森（Roman Jakobson, 1896-1982）

## 生平与学术背景

- **国别 / 时代**：俄国（苏联）/ 捷克 / 美国，1896-1982
- **学术身份**：莫斯科语言学会的创始人之一，捷克布拉格学派和美国纽约语言学小组的发起人之一，[[movements/结构主义]]的奠基人，[[movements/俄国形式主义]]的核心人物之一
- **早期**：中学时代就开始注意收集民间文学语言材料
- **求学**：1914 年完成在拉扎列夫东方语言学院的学习，转入莫斯科大学，1918 年毕业
- **学派创建**：在莫斯科大学期间创建莫斯科语言学会，后在形式主义运动中与诗歌语言研究会合并
- **布拉格时期**（1921-1939）：移居捷克斯洛伐克，成为布拉格语言学小组最活跃成员之一；1926 年会同马捷齐乌斯等人建立布拉格语言学会；完成《俄国现代诗歌》（1921）和《论捷克诗歌》（1923）
- **美国时期**：二战期间流亡美国，在纽约创建语言学小组；在哈佛大学和麻省理工学院教授普通语言学和斯拉夫语言文学
- **著述**：《普通语言学论文集》法语译本 1963 年出版；发表大量关于诗学、语言学尤其是诗律学、语法意义、形式结构等方面的研究文章

## 核心文论贡献

### 1. [[concepts/文学性]]概念

1921 年明确提出："文学科学的对象不是文学，而是'文学性'，也就是使一部作品成为文学作品的东西。"批评当时的文学史家把文学作品只当成"文献"，使研究滑入哲学史、文化史和心理学史等别的学科之中。文学性不存在于某一部文学作品中，而是同类文学作品普遍运用的构造原则和表现手段。

### 2. 文学性的功能阐释：[[concepts/诗性功能]]

- 将诗界定为"具有独立价值的词的形式显现"
- "诗的功能在于指出符号和指称不能合一"——诗歌语言打破符号与指称的稳固逻辑联系
- "一部诗作应该界定为其美学功能是它的主导的一种文字信息"

### 3. 语言六要素六功能说

在《结束语：语言学和诗学》中提出：任何言语交际包含说话者、受话者、语境、信息、接触、代码六个要素，对应情感、意动、指称、诗性（审美）、交际、元语言六种功能。**只有言语交际侧重于信息本身，诗的功能（审美）才占主导地位。**

### 4. 隐喻与转喻的两极

在《隐喻和转喻的两极》中把诗歌分为两类：转喻类（现实主义作品，注重情节叙述和环境描写）和隐喻类（浪漫主义作品，意义隐含在字里行间）。在隐喻类文学作品中诗性功能强，文学性也较强。

### 5. 诗性功能的结构分析

以[[figures/索绪尔]]语言学为依据，把语句构成放在选择轴（纵组合）和组合轴（横组合）上分析。**诗性功能就是要把对等原则由选择轴引到组合轴，形成诗句的对偶**（相当于中国文学中的对仗）。

### 6. 布拉格学派的理论建设

- 1926 年会同马捷齐乌斯建立布拉格语言学会
- 注重语言的功能研究：文学语言最大限度偏离日常实用语言的指称功能，把表现功能放到首位
- 强调共时性研究与历时性研究结合
- 布拉格学派是连接俄国形式主义与英美新批评、法国结构主义的桥梁

## 代表作品

- 《俄国现代诗歌》（1921）——明确提出"文学性"概念
- 《论捷克诗歌》（1923）
- 《历史音位学》
- 《结束语：语言学和诗学》——语言六要素六功能说
- 《隐喻和转喻的两极》——诗歌两极分类
- 《普通语言学论文集》（法语译本，1963）

## 在文论史中的位置

- **所属流派**：[[movements/俄国形式主义]]（莫斯科小组）→ 布拉格学派 → [[movements/结构主义]]
- **独特地位**：跨越三大流派的关键人物——俄国形式主义的核心人物、布拉格学派的创始人之一、结构主义的奠基人
- **前承**：[[figures/索绪尔]]语言学（共时性研究、语言/言语区分、能指/所指）
- **后启**：
  - [[movements/结构主义]]诗论——雅各布森的研究为后来结构主义诗论的发展奠定了基础
  - 法国结构主义——布拉格学派为法国结构主义文论发展开拓了广阔前景
  - 符号学——艺术自主功能与交际功能的辩证关系对符号学产生重大影响
  - 接受美学——布拉格学派后期转向读者预示了接受美学的基本观点
