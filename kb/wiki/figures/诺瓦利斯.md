# 诺瓦利斯（Novalis / Friedrich von Hardenberg）

## 生平

- **国别/时期**：德国，18世纪末-19世纪初
- **身份**：文学家 / 思想家 / 艺术家

## 核心文论 / 艺术贡献

德国早期浪漫主义诗人、思想家，耶拿浪漫派核心成员。代表作《夜之颂》《海因里希·冯·奥弗特丁根》（含'蓝花'意象）。诺瓦利斯将诗歌视为认识世界和精神复苏的途径，追求'世界化'与'神圣化'的浪漫主义理想。他的'蓝花'成为整个欧洲浪漫主义运动的核心象征。
