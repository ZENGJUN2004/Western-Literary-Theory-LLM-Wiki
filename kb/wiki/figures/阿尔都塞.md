# 阿尔都塞（Louis Althusser, 1918-1990）

## 生平与学术背景

- **国别 / 时代**：法国，20世纪中后期
- **生平**：生于阿尔及利亚比尔芒德雷市一个银行经理家庭，先后在阿尔及利亚和法国本土的马赛、里昂等地接受教育；1948年在巴黎高等师范学校获哲学博士学位并留校执教；同年加入法国共产党
- **晚年变故**：1980年因掐死妻子被控，经法院鉴定为精神失常而判无罪，从此退出学界
- **主要著作**：《保卫马克思》（1965）、《读〈资本论〉》（1965，与《保卫马克思》同年）、《列宁和哲学》、《政治和历史》等
- **学派定位**："[[movements/西方马克思主义文论|结构主义的马克思主义]]"的创始人，"[[figures/拉康]]：不是职业文学批评家，仅在《小型戏剧：布尔托拉奇和布莱希特》《就艺术问题复信安德烈·达斯普尔》《论抽象画家克勒莫尼》等文章中谈及艺术，但其哲学思想对[[figures/马舍雷]]、[[figures/伊格尔顿]]等文论家影响极大，形成"阿尔都塞学派"文艺理论

## 核心文论贡献

### 一、意识形态理论："想象性关系的再现"

- **最著名定义**：意识形态是"对个体与其现实存在条件的**想象性关系的再现**"
- **理论结构**：意识形态理论包括两个密不可分的方面——
  - **意识形态国家机器**（强调意识形态的**物质性**）：教会、学校、家庭、政治组织、通讯交往及文化设施等；它为每一个体准备好一个位置，"唤出"个体并赋予名称，通过自我形象或再现的形式给个人提供抚慰性的整体幻景与一致感
  - **意识形态表象体系**（强调意识形态的**精神性**）：人们体验自己与自己的生存条件的关系
  - 两方面旨在弥补精神状态与社会制度、主观世界与外在世界的脱节
- **与拉康的关系**：关于"意识形态"和"意识形态国家机器"的论述实际上融入了拉康"[[concepts/镜子阶段|想象界]]"等思想；"依照症候"阅读理论更是直接从拉康借来（见下）
- **意识形态的无意识性**："即使意识形态以一种深思熟虑的形式出现（如马克思以前的哲学），它也是十分无意识的"——我们关于社会正义、公正、权利与义务的信念，看似有法学、伦理学、宗教、哲学支撑，实为满足"想象"需要而拟造的体系
- **意识形态 vs 科学**：任何意识形态都受阶级利益支配，"在意识形态中，真实关系不可避免地被包括到想象性关系中"；科学则超越狭隘阶级利益，提供对世界的恰当认识——意识形态的主要职能是社会实践或社会生产的，科学的职能则主要是理论的

### 二、艺术与意识形态："意识形态生产出艺术"

阿尔都塞把艺术置于**意识形态与科学之间**：

1. **文学生产首先是意识形态生产**：既然意识形态无所不在、成为主体所能直接对应的客体本身，文学生产所运用的首先是渗透着意识形态的原材料而非中性东西——"每一件艺术作品，都是由一种既是美学又是意识形态的意图产生出来的"
2. **艺术不等于意识形态但离不开意识形态**：意识形态是孕育艺术之母，艺术与之打交道的不是它本身特有的现实，而是意识形态的现实；任何艺术家的自发语言都是意识形态的语言
3. **艺术的特殊职能**：通过意识形态生产来同现存意识形态的实在**保持距离**，使人看破这种实在——
   - 巴尔扎克例：他从未放弃其反动的政治立场，"只是因为他保持了自己的政治概念，他才能产生出自己的作品，只是因为他坚持了他的政治上的意识形态，他才能在其中造成这个内部'距离'，使我们得到对它的批判的'看法'"
   - 托尔斯泰同属此例：艺术的效果在意识形态内部造成距离，使我们"觉察到"它
4. **艺术 ≠ 科学**："艺术以'看到'和'觉察到'的形式，科学则以认识的形式（在严格的意义上，通过概念）"处理同一个意识形态对象——索尔仁尼琴的小说使我们"看到"对"个人崇拜"及其后果的"体验"，但决没有使我们"认识"它们；一部小说不管多么深刻，可能引起对被体验到的后果的注意，但不能确定说出补救这些后果的手段
5. **最完整的艺术定义**："艺术使我们看到的，因此也是以'看到'、'觉察到'和'感觉到'的形式（不是认识的形式）所给予我们的，乃是它从中诞生出来、沉浸在其中、作为艺术与之分离开来并且暗指着的那种意识形态。"

### 三、[[concepts/症候阅读|依照症候的阅读理论]]

- **理论目的**：在重新解释马克思主义的过程中提出。作为科学的马克思主义有一个**理论框架**（problems structure），它不以明显而有意识的形式存在于所支配的著述中，而潜藏在作品深层——一般阅读方法不能发现这种深层无意识结构
- **马克思思想四时期分期**（@马新国#ch21.1）：
  1. 1840-1842：理性自由的人道主义时期（接近康德、黑格尔）
  2. 1844-1845：费尔巴哈人道主义支配期
  3. 1845-1857：转变期——与一切把历史建立在人的本质基础上的理论决裂（全新概念上建立历史政治理论 / 批判一切哲学人道主义 / 把人道主义本身规定为意识形态）
  4. 1857-1883：成熟期——以《资本论》为代表的科学马克思主义
- **阅读方法**：要像结构主义精神分析学家那样，不仅看到白纸黑字的原文，而且看到作者没有明确说出、却埋藏在原文中、构成第二个"**沉默的论述**"的空白之处——把理论框架"从深处拖出来"
- **理论渊源**："书的结构"与书的区别即[[figures/索绪尔]]"语言/言语"的区别；更直接地看，是从[[figures/拉康]]那里借来——本文中没有直接言明之处与看得见的东西同样重要甚至更为重要，无意识存在于文本的空白处，在意识话语的空隙间穿行

### 四、"结构主义的马克思主义"的政治语境

- 主张把马克思主义与[[movements/结构主义]]结合起来，用结构主义"诠释""发掘"马克思主义创始人思想，创建"新马克思主义"
- 反对斯大林主义的经济主义，也反对利用黑格尔派的马克思主义人道主义来清除斯大林主义的做法；反对在哲学中讨论自由、异化、物化和处于历史中心的"人"的地位等主题
- 苏共二十大后的回应：认为非斯大林化形势下，各种资产阶级、小资产阶级世界观（人道主义/人本主义）严重威胁马克思主义的纯洁性，结构主义的马克思主义正是对这一情势的积极回应

## 在文论史中的位置

- **前承**：[[figures/马克思]] + [[movements/结构主义]] + [[figures/拉康]]（想象界与症候阅读）
- **直接影响**：[[figures/马舍雷]]的文学生产理论、[[figures/伊格尔顿]]的审美意识形态生产理论——形成"阿尔都塞学派"
- **后启**：[[movements/文化研究]]的意识形态分析、大众传媒研究（电影叙事方式与节奏将受众接受速度划一、电视风光片复制人们欣赏自然的眼光、商业广告从精神上塑造完美生活观念——表面是文艺美学/生活美学问题，深究起来与"意识形态国家机器"密切相关）
- **与杰姆逊的关系**：[[figures/杰姆逊]]理论杂糅性中包括阿尔都塞"[[concepts/症候阅读|症候阅读]]"；其"政治无意识"同样承续了深层阅读思路

## 评价

- "意识形态国家机器"概念提出了意识形态的**生产和再生产**性质问题，对后工业社会文化传播尤其是大众传媒研究具有深远影响
- 理论含混之处：如何区分进步的与反动的意识形态？意识形态与构造它的思想家的关系如何？（@朱立元#ch11.2.3）
