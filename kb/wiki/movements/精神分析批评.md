# 精神分析批评（Psychoanalytic Criticism）

## 兴起背景

- **时间 / 地域**：19 世纪末至 20 世纪上半叶，发源于维也纳，扩散至整个西方文艺批评界
- **历史与思想语境**：从临床精神病治疗实践出发，把无意识、性本能、梦的解析等概念引入人文领域
- **直接起因**：[[figures/弗洛伊德]] 对艺术家、艺术作品与精神病关系的心理学-医学概括

## 核心主张

1. **文艺本质论**：文艺是被压抑的本能（性）冲动的一种"升华"——经过升华作用，受压抑的力比多通过社会道德允许的途径得到满足
2. **创作动因论**：作家、艺术家从事创作是受"本能的欲望"驱使；创作动因是"性欲的冲动"
3. **文艺功能论**：补偿作用——作家和读者在现实生活中难以实现的欲望通过创作或欣赏文艺作品得到变相满足
4. **文艺-梦同构论**：文艺与梦都表现被压抑欲望；梦的"显现内容/潜在思想"关系犹如作品"形式/意义"关系；释梦方法与文学批评都是揭示"潜在"意义
5. **艺术家论**：艺术家"如一个患有精神病的人那样从一个不满意的现实中退缩下来"，但"知道如何去寻找那条回去的道路"

## 代表人物

- [[figures/弗洛伊德]]（Sigmund Freud, 1856-1939）—— 创始人，全部核心概念提出者
- **霍兰德**（Norman N. Holland）—— 读者反应精神分析批评代表
- [[figures/拉康]]（Jacques Lacan, 1901-1981）—— 结构主义精神分析批评代表，对弗洛伊德做语言学化重新阐释

（三人详见 @朱立元 第 4 章 4.3、4.4、4.5 节，待后续摄入）

## 代表作品

- [[works/释梦]]（Die Traumdeutung, 1899）—— 梦的理论系统阐述
- 《创作家与白日梦》—— 文艺与白日梦类比说的提出文本
- 《图腾与禁忌》（1913）—— 俄狄浦斯情结普遍性的依据
- 《米开朗基罗的摩西》《〈俄狄浦斯王〉与〈哈姆雷特〉》《陀思妥耶夫斯基"弑父"》—— 文艺精神分析个案

## 与相邻流派的关系

- **前承**：柏拉图"迷狂说"——弗洛伊德"艺术家与精神病"论与之异曲同工，但前者从心理学-医学角度做概括
- **后启**：
  - 拉康的结构主义精神分析（与法国结构主义合流）
  - 霍兰德的读者反应精神分析批评（与读者反应批评合流）
  - 弗洛姆的新精神分析文论（与法兰克福学派社会批判合流）
- **同期对照**：与 [[movements/俄国形式主义]]、[[movements/新批评]] 路径不同——精神分析走"心理学-无意识"解释路径，形式主义走"文本内部结构"路径

## 三大内部变体

按 @朱立元#ch4.1 的"研究对象"三分法，第 4 章系统展开为三大变体：

### 变体一：传统精神分析批评（4.3 节，对应"作者"研究对象）

- **核心假设**：①艺术 = 精神病的表现；②艺术 = 幻想/白日梦
- **代表人物**：
  - [[figures/琼斯]]（Ernest Jones, 1879-1958）—— 1910 年运用俄狄浦斯情结说研究《哈姆雷特》
  - [[figures/波拿巴]]（Marie Bonaparte）—— 对[[figures/爱伦·坡]]《黑猫》的分析（[[concepts/压缩与移置]]应用）
  - 弗兰克·卢卡契（1894-1967）——《文学与心理学》（1951）
  - 瑞恰兹——《文学批评原理》（1924）
- **文本观**：把文本看作**作者心理的表征**
- **方法**：把文本视为"病例"，通过故事情节和人物言行揭示作者的心理和无意识欲望
- **局限**：完全局限在作者与文本的关系上；只注意无意识和本能的作用；忽略意识在创作过程中的作用；忽略文学作品的文本的形式和审美因素

### 变体二：读者反应精神分析批评（4.4 节，对应"读者"研究对象）

- **代表人物**：[[figures/霍兰德]]（Norman N. Holland, 1927- ）
- **理论基础**：弗洛伊德**"第二心理地形"**（以自我为中心的人格固定结构）
- **文本观**：把文本看作**作者与读者相互沟通的场所**（继承"掩体/信码系统"设定，但焦点转向读者）
- **核心命题**：
  - 所有文学反应都由三重身份（人体身份/文化身份/个人身份）控制
  - 阅读是"个人交易"——读者根据自己的个性主题主动理解文本
  - 读者与文本关系 = **本我幻想与自我防御**的关系
  - "文本中似乎什么也没有发生，一切都发生在读者身上"
- **代表著作**：[[works/精神分析学与莎士比亚]]（1966，转折点）、[[works/文学反应动力论]]（1968，核心著作）

### 变体三：结构主义精神分析批评（4.5 节，对应"文本"研究对象）

- **代表人物**：[[figures/拉康]]（Jacques Lacan, 1901-1981）
- **改造工程**："语言革命"——用结构主义和后结构主义语言学重新阐释弗洛伊德
- **文本观**：关注文本 + 语言 + 读者（不分析文学框架与作者修辞手段）
- **核心主张**：
  - 无意识是**语言的产物**，像语言一样有结构
  - [[concepts/压缩与移置]] → 隐喻和转喻的修辞过程
  - [[concepts/能指与所指]] → 强调二者分裂，能指成为体系中的主要成分
  - [[concepts/镜子阶段]] → 自我在与外部对象认同中构成（[[concepts/想象态与象征秩序]] → [[concepts/想象态与象征秩序]]）
- **文本阐释范例**：[[works/论窃信案]]对[[works/窃信案]]的分析
- **范式意义**：打破弗洛伊德"无意识不可知"神话，为无意识应用于文学找到中介物——语言

### 三变体范式差异一览

| 维度 | 传统精神分析批评 | 读者反应精神分析批评 | 结构主义精神分析批评 |
|---|---|---|---|
| 代表 | 波拿巴/琼斯 | 霍兰德 | 拉康 |
| 研究对象 | 作者 + 文本 | 读者 + 文本 | 文本 + 语言 + 读者 |
| 文本观 | 作者心理的表征 | 作者-读者沟通场所 | 语言结构的运作场所 |
| 文本作为"掩体" | 是 | 是（继承） | 是 |
| 理论基础 | 弗洛伊德"第一心理地形"（无意识/前意识/意识）+ 力比多 | 弗洛伊德"第二心理地形"（以自我为中心） | 索绪尔语言学 + 弗洛伊德主义 |
| 关注焦点 | 伊德（无意识本能） | 自我（理性调停者） | 能指（语言结构） |

## 后拉康时代的发展

心理分析批评（即本流派的又一译名）将无意识、欲望、压抑、投射等概念引入文学解读，开创了"文学即梦境"的阐释路径：文学文本是无意识的"伪装表达"，梦境逻辑（凝缩、移置）与文学修辞（隐喻、转喻）具有同构性，文学批评类似精神分析治疗——揭示被压抑的真实。

- **与女性主义的深度交汇**：伊里加瑞、[[figures/西克苏斯]]、[[figures/克里斯蒂娃]]等法国女性主义者大量借用拉康理论——克里斯蒂娃（Julia Kristeva, 1941- ）的符号态/象征秩序区分与《恐怖的力量》开辟了精神分析的女性主义文本理论
- **叙事学的延伸**：[[figures/彼得·布鲁克斯]]《Reading for the Plot》将精神分析的欲望驱动理论引入叙事结构分析
- **当代多元发展**：对象关系理论、"后拉康"精神分析批评进一步与性别研究、后殖民理论交叉，形成"弗洛伊德传统"与"拉康传统"两大分支的当代格局
