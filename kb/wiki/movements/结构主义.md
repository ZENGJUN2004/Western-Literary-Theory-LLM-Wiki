# 结构主义（Structuralism）

## 兴起背景

- **时间 / 地域**：20 世纪中叶，法国为主战场
- **直接源头**：[[figures/索绪尔]]结构主义语言学（[[concepts/能指与所指]]、语言符号的差异性）
- **思想扩散**：从语言学扩散到人类学（[[figures/列维-斯特劳斯]]，待生成）、精神分析（[[figures/拉康]]）、文学批评、马克思主义（阿尔都塞）等领域

## 核心主张

1. **关系优先于实体**：意义不在于元素本身，而在于元素之间的关系
2. **结构优先于历史**：共时性结构分析优先于历时性历史叙述
3. **语言为模型**：所有人文社会科学可以以语言学为模型
4. **主体去中心化**：主体不是先于结构的，而是被结构所构成的

## 在文论史中的位置

### 与精神分析批评的关系

[[figures/拉康]]把结构主义语言学引入[[figures/弗洛伊德]]主义，建立**结构主义精神分析批评**——这是精神分析批评第三大模式（详见 [[movements/精神分析批评]] 三大变体表）。

### 关键借用与改造

- [[concepts/能指与所指]]——索绪尔原版 → 拉康**颠倒**：强调能指与所指的分裂，使能指成为体系中的主要成分
- [[concepts/压缩与移置]]——弗洛伊德梦作用 → 拉康重释为隐喻和转喻的修辞过程
- [[concepts/无意识]]——弗洛伊德视为本能代表 → 拉康视为"像语言一样有结构"
- [[concepts/镜子阶段]]——拉康对能指/所指和谐一致瞬间的命名
