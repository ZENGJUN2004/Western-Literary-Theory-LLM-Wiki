# 日内瓦学派（Geneva School）

## 兴起背景

- **时间 / 地域**：20 世纪中叶，瑞士日内瓦大学
- **理论源头**（三重影响）：
  1. 卢梭浪漫主义传统——强调心灵进入另一种心灵的叠合
  2. [[figures/狄尔泰]]历史主义解释学——对本质的研究，文本细读
  3. [[figures/胡塞尔]]、[[figures/海德格尔]]、[[figures/梅洛庞蒂]]现象学——意识批评，现象学还原

## 核心主张

1. **意识批评**——文学作品是人的意识的集中表现形式，文学批评是对这种意识的批评形态
2. **主客体合一**——意识总是与意识对象紧密相关，主客体不可截然二分
3. **现象学还原**——排除意识的先验因素，反对先验论；抛弃前见，达到本质直观
4. **再体验**——"第二体验"对于"原生体验"进行再度体验
5. **意向性**——特别关注作者的意向性和作品语言所表现的作者意向性

## 三代代表

### 第一代
- **雷蒙**（Marcel Raymond）——《从波德莱尔到超现实主义》（日内瓦学派起源之作）；参与性批评/认同性批评/意识叠合式批评
- **贝甘**（Albert Béguin）——"物的在场"、"物中的上帝在场"；现象学色彩较少，唯心论宗教色彩浓郁

### 第二代（核心）
- **[[figures/普莱]]**（Georges Poulet, 1902-1991）——真正的现象学批评代表；《批评意识》为日内瓦学派宣言式代表作；阅读现象学；批评意识三认识方式

### 第三代
- **理夏尔**（Jean-Pierre Richard）——作品结构分析，意向性揭示
- **卢塞**（Jean Rousset）——《形式与意义》；"模式与语言"关系；"双重语调"的"在场"
- **斯塔洛宾斯基**（Jean Starobinski）——"凝视"；"主体间性"与"意向性"；《透明与障碍》《活的眼》
- **米勒**（J. Hillis Miller, 1928-）——早年日内瓦学派，后期"耶鲁四人帮"主将；将现象学批评在英美推行

## 四大特征

1. 对[[concepts/意向性]]的特殊关注
2. 独特的批评方法论——胡塞尔现象学还原的严格性 + 本质直观 + "居中性"态度
3. 反对形而上学——通过还原直观意向性意识和潜在体验模式
4. "个人批评"中的"超个人批评"

## 在文论史中的位置

- **前承**：[[movements/现象学文论]]、[[figures/狄尔泰]]历史主义解释学、浪漫主义
- **同期对照**：[[movements/俄国形式主义]]/新批评——新批评力求斩断作者情感介入，日内瓦学派认为意向性作者与世界相互介入
- **后启**：
  - [[movements/解释学]]理论
  - [[movements/接受美学]]理论
  - 读者反应批评——米勒后期转向解构主义，但"阅读的责任"和"阅读的道德"仍有现象学影响

## 核心命题

> 现象学文论的意义：将作家—作品—读者看作一个主体间性过程，以作品本体论为支点。艺术的中心不是客体（作品），而是人（作家与读者的对话）。

> 文学批评作为意识行为是一种自我意识，或者是自我意识的重审，它是通过自我意识面对世界意识。
