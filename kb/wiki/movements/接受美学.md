# 接受美学（Reception Aesthetics）

## 康斯坦茨学派（Konstanz School）

"康斯坦茨学派"（又作"康士坦茨学派"，Konstanz School）即接受美学研究共同体的别称：20世纪60-70年代兴起于德国康斯坦茨大学，以[[figures/姚斯]]、[[figures/伊瑟尔]]为核心，与联邦德国其他大学的学者（如曼德尔、普列森丹茨）共同构成跨学科的学术流派。1967年姚斯在该校发表就职演说《文学史作为文学理论的挑战》（通常视为接受美学正式诞生的标志，另有1969年正式发表《文学史作为文学科学的挑战》之说）；伊瑟尔《文本的召唤结构》（1970）将其发展为文本-读者互动的完整理论。该学派挑战了传统文学史"作者中心"和"作品中心"的范式，将研究焦点转向**读者及其接受过程**。

## 兴起背景

- **时间 / 地域**：20 世纪 60 年代，德国康斯坦茨大学
- **理论源头**：[[figures/伽达默尔]]哲学解释学（[[concepts/效果历史]]）、[[concepts/空白]]现象学美学（[[concepts/未定点]]/[[concepts/具体化]]）
- **直接动因**：反对孤立、片面地研究文学，反对结构主义化的唯文本趋向，反对作品中心论和单纯作家研究；回应新批评的文本封闭性，恢复文学的历史性和开放性

## 核心主张

1. **读者中心地位**——"文学的唯一对象是读者"；未被阅读的作品只是"可能的存在"
2. **文学总体动态过程**——作家 + 作品 + 读者三者关系
3. **作品意义 = 作者赋予 + 接受者赋予**——读者对作品意义的填充是能动的、决定性的
4. **文学史 = 效果史**——文学的历史是文学被读者接受的历史
5. **[[concepts/召唤结构]]**——文本以"空白"和"未定点"邀请读者参与意义建构；读者阅读感受与期待视野一致则索然无味，超出则感到振奋

### 姚斯的接受理论

1. **[[concepts/期待视野]]**：读者阅读前由以往阅读经验、审美趣味、文化素养等构成的期待结构，决定对作品的接受方向
2. **审美距离**：读者期待视野与作品之间的距离，决定接受的效果——距离为零则完全代入，距离过大则漠然视之
3. **垂直接受与水平接受**：文学接受同时具有历时性（垂直接受）与共时性（水平接受）两个维度
4. **文学史即接受史**：文学的历史是文学作品被读者接受并产生影响的历史，只有经读者实现才能进行
5. **文学演变规律**：新作品以已完成的作品为背景，成功作品很快变得习以为常，直到更新的艺术形式崛起

### 伊塞尔的文本理论

1. **隐含的读者**：文本内部预设的理想读者位置，是文本结构的一部分
2. **召唤结构**：文学作品充满"空白"和"未定点"，邀请读者参与意义建构
3. **意义事件**：文学意义不是文本固有属性，而是在阅读过程中发生的事件

## 主要著作

- [[figures/姚斯]]《文学史作为文学理论的挑战》（1967）
- [[figures/姚斯]]《审美经验一辩》（1972）— 后期修正，回归审美经验
- [[figures/伊塞尔]]《文本的召唤结构》（1970）、《隐含的读者》（1972）
- 艾柯《开放的作品》（1962）— 接受理论的先声

## 理论推进

- **美国读者反应批评**——费希"情感文体学"、普莱"内在感受"说、卡勒"文学能力"说
- **法国"新"新批评**——受罗兰·巴特影响
- **东德瑙曼**——吸收康斯坦茨论点，从马克思理论出发，重新确立文本决定性地位

> 两者（美国读者反应批评、法国"新"新批评）几乎取消了文本的地位，片面地发展了接受美学中主观性的一面，将读者的能动作用推到极点。

## 姚斯后期的理论修正

1972年《审美经验一辩》中，姚斯对自己前期激进的读者中心立场进行了清算：由于排除了基本的审美经验，接受美学与其理论反思成为一种"空的、与活生生的人生体验相隔离的思考方式"。他后期将"期待视野"从美学中心移开，转而关注审美经验问题，重新引进"愉悦"概念——标志着接受美学从激进读者中心论向更全面审美经验论的转变（详见 [[concepts/期待视野]]）。

## 方法论遗产

- 开创了从"作者中心/文本中心"向"读者中心"的范式转换
- 将文学史研究从作品编年史转化为接受效果史
- 为后来的文化研究、媒介研究中的接受分析提供了理论工具
- 影响了文学教育的变革——从"教作品"转向"教阅读"

## 局限性

1. 回避美的本质、艺术本质等根本问题
2. 偏重读者接受过程，较少论及作品文本形式与作家创造
3. 姚斯缺乏具体充分论证
4. 对社会制约作用论述单薄
5. 80 年代初势头大减
