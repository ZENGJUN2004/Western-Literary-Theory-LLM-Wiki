# 省略（ellipsis）

## 核心定义

[[concepts/省略|省略]]（ellipsis）是[[figures/热奈特]]（Gérard Genette）在《叙事话语》（*Narrative Discourse*, 1972）中提出的叙事时间分析范畴，指叙事时间**完全不覆盖**某些故事时间——即某个事件或事件段落在叙事中被完全跳过，只字未提。省略是叙事节奏控制的重要手段，也是叙事"空白"的主要来源。

## 理论来源

### 热奈特的叙事时长理论

热奈特将故事时间与叙事时间的关系分为五种：场景（≈）、摘要（<）、省略（=0）、停顿（叙事>0，故事=0）、扩展（>>）。省略是时长关系的极端情况——叙事时间对故事时间的覆盖率为零。

### 俄国形式主义的"本事-情节"区分

[[figures/什克洛夫斯基]]的"本事"（fabula）与"情节"（sjuzhet）区分暗示了叙事中必然存在省略——情节总是对本事的有选择性重组，被省略的"本事"部分构成了叙事之外的"叙事外时间"。

## 核心论述

### 1. 省略的类型

| 类型 | 说明 | 例子 |
|---|---|---|
| **情节内省略** | 故事中有但叙事中不呈现的事件 | 《红楼梦》中贾母的日常琐碎活动 |
| **情节间省略** | 两个叙事段落之间的时间跳跃 | "三年过去了……" |
| **故意省略** | 作者有意省略以制造悬念或意义空白 | 侦探小说中关键证据的隐瞒 |
| **无意识省略** | 叙事惯例导致的自动省略 | 人物日常作息、例行公事 |

### 2. 省略的叙事功能

| 功能 | 说明 |
|---|---|
| **节奏控制** | 省略加快叙事节奏，使叙事能够跨越漫长时期 |
| **悬念制造** | 故意省略关键事件，制造读者的悬念和想象 |
| **主题强化** | 省略本身可以成为主题——什么被省略、为什么被省略 |
| **意识形态运作** | 某些经验被系统性省略（如女性、底层的声音） |
| **阅读参与** | 空白迫使读者填补省略部分，积极参与意义生产 |

### 3. 省略与"空白"理论

[[concepts/空白]]是接受美学和读者反应批评的核心概念。省略是文本中客观存在的空白，而"空白"是读者主观感知的空缺。省略作为文本策略，创造了读者填补空白的阅读任务。

### 4. 省略的限度

叙事不能省略一切——如果全部省略，就没有故事可言。省略的前提是读者能够"看到"省略的边界——叙事必须通过上下文暗示被省略的部分的存在。

## 学术影响

1. **叙事学的核心范畴**：省略理论为理解叙事时间结构提供了精确的概念工具
2. **接受美学的资源**：伊塞尔的"空白"理论建立在省略概念之上
3. **电影剪辑理论**：电影的"淡入淡出"、"跳切"等手法本质上是视觉化的省略
4. **女性主义批评**：揭示叙事中哪些群体的经验被系统性省略
