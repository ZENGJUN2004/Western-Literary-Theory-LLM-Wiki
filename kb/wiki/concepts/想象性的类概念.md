# 想象性的类概念（imaginal type concept）

## 核心定义

[[concepts/想象性的类概念|想象性的类概念]]是[[figures/维柯]]诗性智慧理论的另一核心机制，指**原始民族对同类事物缺乏抽象的类概念，但用形象鲜明的个别具体事例来代表同类事物的认知方式**。这不是抽象性的类概念，而是"想像性的类概念"——通过个别的、具体的、感性的形象来把握普遍性。

维柯将其与[[concepts/以己度物]]并列为诗性智慧的两大基本认知方式。

## 理论来源

### 维柯的《新科学》

维柯在《新科学》中指出，原始人的思维特点是：人心受本性的驱遣，喜爱一致性，因此用形象鲜明的个别具体事例来代表同类事物。例如，见到年长的男人都叫"爸"或"叔"——这不是一个抽象的"父亲"概念，而是一个具体的、形象的、可感的类概念。

### 与柏拉图"理念"的对比

维柯的想象性的类概念与柏拉图的"理念"（idea）形成鲜明对比：
- 柏拉图的理念是抽象的、普遍的、超越感性世界的
- 维柯的想象性类概念是具体的、个别的、扎根于感性经验的
- 前者是哲学思维的产物，后者是诗性思维的产物

## 核心论述

### 一、想象性的类概念的特征

| 特征 | 说明 |
|---|---|
| **个别性** | 以具体个例为代表，而非抽象概括 |
| **感性性** | 类概念通过可感形象呈现，而非逻辑概念 |
| **典型性** | 所选个例具有充分的代表性，能"以少总多" |
| **历史性** | 想象性的类概念是特定历史阶段（原始时期）的产物 |
| **诗性** | 与诗歌创作中的"典型化"有直接关联 |

### 二、想象性的类概念与典型化理论

维柯的想象性的类概念被视为后世"典型化"理论的远祖：
- 亚里士多德《诗学》中的"诗比历史更哲学"——诗的普遍性
- 恩格斯的"典型环境中的典型人物"——现实主义典型理论
- 卢卡契的典型理论——特殊性与普遍性的辩证统一

三者都与维柯的想象性的类概念有理论关联，但维柯的独特贡献在于将典型化追溯到人类最初的认知方式。

### 三、想象性的类概念的神话功能

想象性的类概念是神话生成的认知基础：
- 神话中的英雄（如赫拉克勒斯）是一个想象性的类概念——代表所有英雄
- 神话中的神祇（如宙斯）是一个想象性的类概念——代表所有天空力量
- 神话叙事通过想象性的类概念将普遍性嵌入具体故事

## 学术影响

1. **典型化理论的源头**：维柯的想象性的类概念被视为典型化理论的最早表述
2. **浪漫主义的共鸣**：赫尔德、诺瓦利斯等浪漫主义者从维柯的理论中汲取灵感
3. **马克思主义文论的资源**：卢卡契、杰姆逊等马克思主义文论家讨论维柯的历史诗学
4. **人类学的继承**：列维-布留尔的"原始思维"理论引用了维柯的观点
5. **文学教育的启示**：想象性的类概念为文学教学中的"典型形象分析"提供了理论依据
