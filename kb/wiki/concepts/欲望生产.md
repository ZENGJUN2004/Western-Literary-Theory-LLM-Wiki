# 欲望生产（desiring-production）

## 核心定义

[[figures/德勒兹]]与居塔里在《反俄狄浦斯》中提出的核心概念。他们将无意识作为"欲望生产"来研究，拒绝通过人的需要来给欲望下定义——"欲望不是感到需要什么东西，也不是感到自己的对象的缺乏"。欲望和任何生产一样，创造现实、人的存在的世界。

## 新欲望观

与传统的欲望观决裂：

| 传统 | 德勒兹/居塔里 |
|---|---|
| 欲望 = 感到需要什么 | 欲望 = 生产力量 |
| 欲望 = 对象的缺乏 | 欲望 = 创造现实 |
| 弗洛伊德：欲望生产变成表象 | 欲望生产 = 社会生产 |

借助马克思的"生产理论"来克服弗洛伊德主义的局限。欲望和任何生产一样，创造现实、人的存在的世界。在产生个体同自然界和社会的深刻联系的同时，欲望生产也创造个体本身。

## 欲望机

"欲望机"由三部分组成：

| 组成部分 | 功能 |
|---|---|
| **工作器官** | 欲望首先是生存行动和创造的欲望 |
| **无器官的躯体** | 欲望同时也是死亡和停止的欲望 |
| **主体** | 同工作器官相衔接，建立工作器官和无器官的躯体之间的真正关系 |

欲望机和无器官的躯体之间的关系发展经历几个阶段：
1. 冲突和相互排斥力
2. 吸引力
3. 在新的生产机水平上的永久调和

## 对弗洛伊德的批判

- 弗洛伊德发现了"欲望机"，重视"欲望生产"的研究，但不彻底
- 破坏了欲望生产的秩序，使欲望生产变成表象
- 把无意识规定为纯主观的象征界，把无意识说成和人的梦、幻想相同的想象界
- 歪曲了欲望的实质，使欲望失去了社会内容
- 精神分析使资本主义得以操纵欲望，使欲望变成剩余价值

## 艺术在欲望生产中的地位

- "正是艺术从达到它自身的伟大、完美之时起，就创造了非规则化和非地域化的链锁，这些链锁产生欲望机并让欲望机运转起来"
- 艺术和科学具有现代社会中最强的"精神分裂力"
- 艺术成为疏离主流意识权力最为便捷的形式
- 释放人们的欲望才能塑造"新的人性"
