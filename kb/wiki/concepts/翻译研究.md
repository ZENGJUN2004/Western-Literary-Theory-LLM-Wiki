# 翻译研究（translation studies）

## 核心定义

[[concepts/翻译研究|翻译研究]]是二十世纪后期在英语世界兴起的跨学科领域，标志是1995年[[figures/巴斯内特]]（Susan Bassnett）和[[figures/勒菲弗尔]]（André Lefevere）编辑的译丛"The Translation Studies Series"。翻译研究超越了传统语言学派的"对等"问题，将翻译置于文化、政治和历史的语境中考察——这就是所谓的**"翻译转向"**（Translation Turn）。翻译不再被视为语言的简单转换，而是文化间权力关系、意识形态运作和身份建构的复杂场域。

## 理论来源

### 施莱尔马赫的翻译理论先声

[[figures/施莱尔马赫]]（Friedrich Schleiermacher）在1813年《翻译的方法》中提出两种翻译策略：让作者靠近读者（归化），或让读者靠近作者（异化）。这一二分法为后来的文化转向提供了理论资源。

### 俄国形式主义的"陌生化"思想

[[figures/什克洛夫斯基]]的陌生化理论与翻译中的异化策略相通——翻译应该保持源文本的"他者性"，拒绝平滑的归化。

### 解构主义的翻译观

[[figures/德里达]]认为翻译是"不可避免的"——任何文本都在翻译之中，语言本身就具有翻译性。[[concepts/修辞阅读]]也指出翻译揭示了语言的不可决定性。

## 核心论述

### 1. 翻译研究转向的核心命题

| 命题 | 说明 |
|---|---|
| 翻译是文化操纵 | 翻译总是受到目标文化的意识形态和诗学规范制约 |
| 翻译是重写 | 勒菲弗尔提出翻译是一种"重写"（rewriting），受制于意识形态和诗学 |
| 翻译是权力关系 | 翻译中的归化/异化选择反映文化权力的不对称 |
| 翻译是身份建构 | 翻译参与目标文化的身份塑造和自我理解 |

### 2. 韦努蒂的异化翻译理论

韦努蒂（Lawrence Venuti）在《译者的隐身》（*The Translator's Invisibility*, 1995）中提出：
- **归化**（domestication）：使译文读起来像原创文本，消解源文本的他者性
- **异化**（foreignization）：故意保留源文本的异质性，抵抗目标文化的同化
- 韦努蒂批评英美翻译传统过度使用归化策略，导致"译者的隐身"
- 异化翻译是一种伦理-政治实践：尊重他者，抵抗文化帝国主义

### 3. 操纵学派的贡献

[[figures/巴斯内特]]和[[figures/勒菲弗尔]]领导的操纵学派（Manipulation School）强调：
- 翻译永远不是中立的语言转换
- 翻译受到"赞助人"（patronage）的控制
- 翻译是目标文化中文学系统的有机构成部分

### 4. 文化翻译

翻译研究将翻译概念扩展到文化层面——文化之间的交流、理解和转译都可以被视为翻译活动。这一扩展使翻译研究与后殖民批评、文化研究紧密交织。

## 学术影响

1. **翻译学的学科独立**：翻译研究从语言学的附庸成为独立学科
2. **后殖民批评的资源**：斯皮瓦克、巴赫金等从翻译角度分析殖民/后殖民文化关系
3. **女性主义批评的介入**：女性主义者指出翻译本身就是性别化的活动——译者（常被想象为女性）对原文的"背叛"
4. **比较文学的重构**：翻译转向推动比较文学从影响研究转向接受研究和文化翻译研究
