# 解构（deconstruction）

## 核心定义

[[figures/德里达]]创立的批评方法与哲学策略。解构即消解[[concepts/逻各斯-logos|逻各斯中心主义]]、[[concepts/语音中心主义]]、在场形而上学话语，而以思想和语言游戏对"中心化"的结构主义加以拆解。

## 解构策略

### 用"意义链"取代"结构"

德里达对结构主义的"结构"论加以解构，其解构的方式是用"[[concepts/意义链]]"去取代"结构"，从而避免结构的先验同一性危险：
- 意义链是终端开放的、非目的论的
- 排除了认为在系统中有一个具有统治作用的整体的想法
- 既是空间的又是时间的，不会降到整体或对象的地位

### 颠覆二元对立

- 颠倒说话和书写的次序
- 移动中心和边缘的位置
- 消解一切不平等的对立概念
- 颠倒在本质与现象、内容与表现、隐含与显现、物质与运动关系上的传统观念

### 四核心概念

| 概念 | 功能 |
|---|---|
| [[concepts/异延]]（différance） | 以意义不定取代理解的意义确定性 |
| [[concepts/播撒]]（dissemination） | 揭穿文本的裂缝 |
| [[concepts/踪迹]]（trace） | 说明始源的迷失和本源的空缺 |
| [[concepts/替补]]（supplement） | 书写是说话的补充形式 |

## 方法论意义

### 正面意义

1. **话语转型**：实现了文艺理论研究的话语转型，刷新了人们对语言与表达、书写与阅读、语言与文化、文学与社会等方面的认识
2. **思维换型**：解除人们头脑中根深蒂固的传统一元论，消解思维定式——追求一个至高无上的权威、一个绝对正确的标准、一个一成不变的等级模式
3. **文本解放**：作品与创作者的依附关系被解构，获得完全的独立
4. **政治实践**：通过文学解构和重写文学史施行一种政治实践

### 负面问题

1. **虚无主义危险**：一味强调差别而无视统一，走向自己的反面
2. **意义游戏**：在告别了终极意义和价值关怀以后，不再是沉重的哲性思考，而成为"文本的快乐"的游戏
3. **"德里达式的瘟疫"**：整个学术界已经感染了"德里达式的瘟疫"（耶鲁四人帮语）
4. **自我指涉矛盾**：德里达最终仍不得不用形而上学的话语讲着自己的构想——如果彻底，他就必然丧失其话语逻辑基础
