# 生态批评（ecocriticism）

## 核心定义

格罗特费尔蒂（Cheryll Glotfelty）的经典定义："**生态批评研究文学与物理环境之间的关系**。正如女性主义批评从性别意识视角考察语言和文学，马克思主义批评把生产方式和经济阶级的自觉带进文本阅读，生态批评运用一种**以地球为中心的方法研究文学**。"简言之：生态批评是探讨文学与自然环境之关系的批评，是文学研究在"环境"维度上的重新定向。

## 展开论述

### 学科制度化历程

| 时间 | 事件 |
|---|---|
| 1978 | 威廉·鲁克尔曼（William Rueckert）《文学与生态学：生态批评的实验》在《衣阿华评论》发表，首次明确"将文学与生态学结合起来"，首提"生态批评"术语 |
| 1992 | "文学与环境研究会"（ASLE）在美国内华达大学成立 |
| 1993 | 帕特里克·墨菲（Patrick Murphy）创办《文学与环境跨学科研究》（ISLE）杂志 |
| 1994 | 克洛伯尔《生态批评：浪漫的想象与生态意识》出版 |
| 1995 | 布依尔（Lawrence Buell）《环境的想象：梭罗、自然书写和美国文化的构成》出版，里程碑式著作 |
| 1996 | 格罗特费尔蒂、弗罗姆主编《生态批评读本》出版，生态批评获得理论纲领 |
| 1998 | 英国第一本论文集《书写环境》（克里治、塞梅尔斯主编）出版 |

### 思想背景

- 两大危机：自然生态危机（罗马俱乐部1972《成长的界限》警告增长极限）与精神生态危机（消费社会的人的断片化），均源于现代性
- 生态学词源：希腊语oikos（房子、住所）；海克尔1886年界定"生态学是关于有机体与周围环境关系的全部科学"
- 1970年"生态主义"（Ecologism）兴起；生态哲学、生态神学、生态政治学、生态女性主义、深生态学（Deep ecology）共同构成生态文化
- 理论敌手：反对[[figures/德里达]]"文本之外一无所有"的文本中心主义——贝特（Jonathan Bate）："生态诗学主张我们必须牢牢把握一种可能性，即诗歌的文本尺度可以使我们回忆起人类最古老的知识：**没有大地尺度，我们就不复存在**"
- 布依尔的矛头指向现代理论"对真实世界指涉维度的丧失"，核心任务是让读者重新去与自然"接触"

### 六大基本特征

1. 以研究文学中的**自然生态和精神生态**问题为主，把握文学与自然环境互涉互动关系
2. 从生态文化角度**重新阐释阅读传统文学经典**，解读被遮蔽的生态文化意义，重建人与自我、他人、社会、自然、大地的审美关系
3. 对人的主体性问题保持"政治正确"——既不持人类中心主义立场，也不持绝对自然中心主义立场；主张人类由"自我意识"向"**生态意识**"转变
4. 将文学研究与**生命科学**相联系，具有跨学科特性
5. 继承绿色革命意识形态，同时强调不背离**文学精神和文学话语**，尽可能在文学文本形式和艺术手法层面展开叙事
6. 从**生命本质和地球双重视野**考察人类过去与未来的存在状态

### 深生态学

- 奈斯（Arne Naess）1982年首提"深生态学"（Deep ecology）："深"与"浅"相对，触及现代性弊端最核心问题
- 前驱：施韦兹、泰勒"尊重生命"理论，莱奥波德"大地伦理学"
- 两大原则：**自我实现**（self-realization）与**生态中心平等**（ecocentric equality）
- 沃斯特（Donald Worster）："我们今天所面临的全球性生态危机，起因不在生态系统自身，而在于我们的**文化系统**"

### 批评与争议

- 达纳·菲利普斯《生态论的真相》讥讽生态批评"旧瓶装新酒"：理论创新不足、情感叙述多于学理论证、对进化论与生态理论的文学化消化困难
- 教材的辩护：生态批评在"文本喧哗""话语游戏"中走出来，"开始俯身生养死葬的大地，直面并关心人类存在的真实困境，这是不可否定的事实"

## 方法论意义

1. **文学研究的环境转向**：为文学批评补上长期缺失的"自然"维度，使环境、物种、大地成为与阶级、性别、种族并列的分析范畴
2. **跨学科实践**：从生命科学、人文地理、社会人类学、哲学、史学、宗教及性别种族研究中吸取阐释模型
3. **现代性批判与东方资源**：以"天人合一"、中庸之道等东方思想纠偏西方现代性，推动东西方生态话语整合
4. **文学性承诺**：在介入生态政治的同时坚持文学话语自身的形式与审美品格——批评的实践性与文学性并重
5. 为[[concepts/生态文学]]提供理论方法，与生态美学、环境人文学（environmental humanities）合流
