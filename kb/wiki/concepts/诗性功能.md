# 诗性功能（poetic function）

## 核心定义

[[concepts/诗性功能]]是[[figures/雅各布森]]在语言六要素六功能说中提出的概念，指言语交际侧重于信息本身（即言语本身）时占主导地位的功能。当言语突出指向自身时，其诗性功能才突现出来，其他实用功能才降到最低限度。诗性功能是[[concepts/文学性]]的功能阐释和具体实现方式。

## 源流

### 从文学性到诗性功能

雅各布森在早期活动中提出"[[concepts/文学性]]"概念之后，始终努力从语言学的角度来说明文学性。他从分析诗歌语言入手，把诗歌放置在语言的交际环境中加以探讨，试图从语言功能上来阐释文学性，说明诗歌语言的特征。这一探索轨迹展现了雅各布森由[[movements/俄国形式主义]]经布拉格学派，最终到现代[[movements/结构主义]]的探索足迹。

### 诗的本质：词的形式显现

雅各布森以类比方式界定诗的本质：造型艺术是视觉表现材料的形式显现，音乐是音响材料的形式显现，舞蹈是动作材料的形式显现，**诗便是具有独立价值的词的形式显现**。诗的本质不在指称、叙述外在世界的事物，而在具有表达目的的诗歌语言（词）的形式显现。

## 关键命题

### 1. 诗的功能在于指出符号和指称不能合一

> "诗的功能在于指出符号和指称不能合一"

诗歌（文学）语言往往打破符号与指称的稳固的逻辑联系，而为能指与所指的其他新的关系和功能（如审美）的实现提供可能。

### 2. 诗作是美学功能为主导的文字信息

> "一部诗作应该界定为其美学功能是它的主导的一种文字信息"

诗歌语言虽有提供信息的功能，但应以"自指"的审美功能为主。

### 3. 语言六要素与六功能说

雅各布森在《结束语：语言学和诗学》中提出，任何言语交际都包含六个要素，与之相应有六种功能：

| 要素 | 功能 |
|---|---|
| 说话者 | 情感功能 |
| 受话者 | 意动功能 |
| 语境 | 指称功能 |
| **信息** | **诗性功能（审美）** |
| 接触 | 交际功能 |
| 代码 | 元语言功能 |

- 侧重于语境→指称功能
- 侧重于说话者→情感功能
- 侧重于受话者→意动功能
- 侧重于接触→交际功能
- 侧重于代码→元语言功能
- **只有言语交际侧重于信息本身，诗的功能（审美）才占主导地位**

"信息"指言语本身，当言语突出指向自身时，其诗性功能才突现出来。

### 4. 诗性功能越强，语言越指向自身

诗歌的诗性功能越强，语言就越少指向外在现实环境，越偏离实用目的，而指向自身，指向语言本身的形式因素（如音韵、词语和句法等）。

### 5. 隐喻与转喻的两极

雅各布森在《隐喻和转喻的两极》中把诗歌分为两类：

- **转喻类**：一般现实主义作品，转喻结构居支配地位，注重情节叙述和环境描写，通过转喻表现人物与环境的关系，主要指向环境（如罗斯的英雄史诗）
- **隐喻类**：浪漫主义作品以隐喻为主导，很少通过清楚地描写外在具体特征来直接表述意义，而是把意义隐含在字里行间（如俄国抒情诗）

**在隐喻类文学作品中，诗性功能强，因而文学性也就较强。**

### 6. 诗性功能的结构分析：选择轴与组合轴

雅各布森以[[figures/索绪尔]]语言学为依据，把语句构成放在选择轴和组合轴上分析：

- **选择轴**：近似于索绪尔语言学的纵组合概念，语句中排列的词是从众多能够替换的对等词语中选择出来的
- **组合轴**：基本等于索绪尔语言学的横组合概念，上下文之间的联系

**诗性功能就是要把对等原则由选择轴引到组合轴，形成诗句的对偶。**（相当于中国文学中的对仗。）

雅各布森努力寻找发音和意义上对应、语法功能相同的词语，寻找由一行对称诗句组合而成的诗节，并由此发掘诗的内在结构。
