# 意识形态批判（ideology critique）

## 核心定义

意识形态批判是西方马克思主义文论的核心方法与基本姿态：揭示资产阶级意识形态如何通过文化、艺术、传媒"调节大众生活、控制个体生存、灌输思想"，使现存统治合法化，从而瓦解压抑人、操纵人的中心权力话语，使人重新获得解放。@最新文论教程 第六章以 [[figures/伊格尔顿]] 对意识形态概念史的梳理为线索，将其确立为西马文论的中心任务。

## 概念史（伊格尔顿的梳理）

@最新文论教程 依伊格尔顿的考察梳理"意识形态"一词的语义流变：

| 阶段/人物 | 界定 |
|---|---|
| **德特拉西**（Destutt de Tracy, 1754-1836） | 《意识形态概论》首先使用，指观念学说和关于人的心灵、意识的生命科学 |
| **马克思、恩格斯** | 作为与经济形态相对应的历史唯物主义重要范畴；"资产者的假仁假义的虚伪的意识形态用扭曲的形式把自己的特殊利益冒充为普遍的利益" |
| **孔德** | 据拿破仑之说，认为意识形态是人们编造出的理论和幻想的诡辩术，是一种**虚假意识** |
| **曼海姆** | 意识形态是歪曲客观现实的教义体系，科学与意识形态相互区别 |
| **卢卡契** | 剥削阶级的意识形态具有虚假性和欺骗性 |
| **阿多诺** | "意识形态就是非真实性，即虚假意识和谎言" |
| **弗洛姆** | "意识形态既是真理，又是谎言" |
| **马尔库塞** | 意识形态就是维护现存统治的一种辩护 |
| **哈贝马斯** | 意识形态是"现存的非真理" |
| **阿尔都塞** | 意识形态是"对个体与其现实存在条件的想象性关系的再现"——不是虚假观念或科学，而是社会体验的表象系统 |
| **杰姆逊** | "意识形态在某种意义上说是异化在意识或思想领域内所采取的形式，它是异化了的思想" |

## 意识形态的运作机制

- 现代工业社会"通过电影、电视、广播、画刊、唱片、畅销书调节大众生活，控制个体生存，灌输思想，将强化的思维方式作为法则和价值标准强加给人们"。
- 在获得权力话语以控制民众的同时，"使人丧失内在的自由、独立的生命意志和思想能力"；"今天，每个社会阶层的意识都有可能受到意识形态的限制或腐蚀"。
- 资产阶级意识形态的目的在于**使资产阶级统治合法化**：通过复制美好的神话，使人们把受支配的生活当作愉悦的生活，"把意识的灌输当作自我自觉的意识，把社会强加于个体的控制错看成个人的自由必然体现"。
- 因此"必得进行意识形态批判，以解除现代社会意识形态的异化状态，瓦解那种不断加强的压抑人、操纵人的中心权力话语，使人重新获得'解放'"。

## 文学与意识形态的关系（伊格尔顿）

- 伊格尔顿的定义："所谓意识形态，是指我们的说话和信仰，与我们所生活的社会权力结构和权力关系联结的方式"；具体指"那些与社会权力的维护和再生有着某种联系的感觉、评价、理解和信仰的模式"。
- 反对两种对立观念：既反对"文学作品仅仅是占统治地位的意识形态的反映"的庸俗马克思主义，也反对文学超越意识形态的模式（费希尔、卢卡契）。
- 借助阿尔都塞和马舍雷：**艺术包含于意识形态，又尽量使自己与意识形态保持距离**，让人"感觉"或"觉察"到产生它的意识形态——"文学通过使用意识形态向意识形态挑战"；文本"挖空"意识形态，作品的意义"在于这些含义之间的歧异而不是它们之间的一致"。
- 立场："文学理论和文学批评不论显得多么公允，从根本上说它们永远具有强烈的政治性。"

## 方法论谱系

- **法兰克福学派**：[[concepts/文化工业]] 批判即意识形态批判在大众文化领域的落实——[[figures/阿多诺]]、[[figures/霍克海默]] 揭示文化工业"把人们再现为整个社会所需要塑造出来的那种样子"；[[figures/马尔库塞]] 的单向度批判、[[figures/弗洛姆]] 的社会性格分析。
- **葛兰西**：[[concepts/文化霸权]] 理论揭示意识形态通过知识与道德领导制造"同意"。
- **阿尔都塞**：意识形态国家机器、意识形态再生产、[[concepts/症候阅读]]。
- **后现代延伸**：[[figures/博德里亚]] 的传媒符码分析、[[figures/杰姆逊]] 的政治无意识，被视为西马意识形态批判向消费社会/后现代语境的转换。
