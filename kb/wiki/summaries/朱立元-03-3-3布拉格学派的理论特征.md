# 布拉格学派的理论特征

> **由相邻切片综合**（raw 目录无 03-3-3 专切片；本页综合 3.1.2 同题 summary、3.3 节及其 3.3.2 切片）。原书在俄国形式主义概述（3.1.2）与雅各布森（3.3）两处均论及布拉格学派，本页侧重其与雅各布森文学性理论的衔接。来源：[[@朱立元#ch3.3.3]]。

## 核心论点

1. **以"结构"和"功能"为基本点**：1920 年[[figures/雅各布森]]移居捷克，1926 年与马捷齐乌斯等人建立布拉格语言学会（特鲁别兹科依等俄国学者亦参加）。该派一方面肯定[[figures/索绪尔]]的共时性语言学研究，另一方面反对脱离历史谈共时，主张共时分析与历时分析结合，以"结构""功能"两个基本点构建体系；1935 年起采用结构主义名称，即捷克结构主义（[[summaries/朱立元-03-1-2布拉格学派的理论特征]]）。
2. **文学语言的功能界定**：文学语言的特点是最大限度地偏离日常生活实用语言的指称功能，而把表现功能放到首位。雅各布森将其精确化为语言六要素六功能说——唯有言语交际侧重于信息本身时，[[concepts/诗性功能]]（审美功能）才占主导，"一部诗作应该界定为其美学功能是它的主导的一种文字信息"（[[summaries/朱立元-03-3-2文学性与诗性功能]]）。
3. **作品是与社会环境相关的系列结构**：捷克结构主义认为文学作品不只是言语或文学性的东西，而是一种与各种社会环境密切相关的系列结构，为法国结构主义文论开拓了前景；穆卡尔茹夫斯基更提出作品印成书只具潜在审美价值，须在读者阅读活动中才能实现，预示了接受美学。
4. **桥梁地位**：布拉格学派上承[[movements/俄国形式主义]]（[[concepts/陌生化]]、文学性问题的延续），下启英美新批评与法国结构主义，是现代西方文论的关键中转。
