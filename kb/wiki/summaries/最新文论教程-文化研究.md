# 文化研究

> 本章对应王岳川《当代西方最新文论教程》第十一章"文化研究的文论旨趣"（pp.441-484），并整合第八章第八节汤姆林森"文化帝国主义研究"（pp.378-386）。内容涵盖文化研究的理论源头与命名（文艺社会学传统、霍伽特与伯明翰当代文化研究中心）、布迪厄文化研究的当代拓展（场域、习性、文化资本、反思社会学、身体视域）、博德里亚消费文化理论（消费社会、符号消费、大众传媒、类像与超真实），以及汤姆林森对文化帝国主义四层话语的辨析。

## 一、理论源头：文艺社会学与社会批判理论

文化研究有深广的文化资源和理论来源：不仅有社会学理论背景，也有社会批判理论资源，还有当代哲学思想话语的参照。其理论源头可追溯到19世纪末至20世纪初的**文化社会学研究**。对文学的社会学研究使文学研究突破作家—作品的格局，从更广阔的社会文化大背景阐释文学的起源、状态、命名与社会文化意义。

@最新文论教程 列举的文艺社会学方法论资源：

| 理论家/流派 | 核心观点 |
|---|---|
| 格罗塞"经济唯物主义派" | 从原始艺术入手，将艺术起源归结为社会生产力发展 |
| 普列汉诺夫"中间环节"说 | 生产活动通过宗教、巫术（现代则为政治、道德、哲学）等中间环节影响艺术 |
| 卢卡契等"理论批判的文艺社会学" | 考察社会阶级结构在文学作品中的反映，强调理论思辨与批评 |
| 弗里契《艺术社会学》 | 明确提出建立艺术社会学学科，寻绎艺术与社会文化的必然联系 |
| 阿诺德·豪塞"艺术社会学" | 多角度研究艺术现象，讨论艺术消费、艺术市场、传播媒介、大众艺术乃至"艺术的消亡" |
| 罗贝尔·埃斯卡皮"文学社会学" | 吸收经济学、传播学、信息论方法，将作家当作职业的人来研究 |
| 吕西安·戈德曼"发生学结构主义" | 研究作品同社会结构及特定社会集团思想体系结构之间的对应关系 |

文化研究的理论资源除西方马克思主义者外，还有解构主义理论家[[figures/福柯]]、[[figures/拉康]]、[[figures/德里达]]、[[figures/巴尔特]]、[[figures/德勒兹]]和[[figures/博德里亚]]。

## 二、命名与理论向度：霍伽特与伯明翰中心

英国伯明翰大学"**当代文化研究中心**"的[[figures/霍加特]]（Richard Hoggart, 1918- ）教授起了关键的命名和理论阐释作用。

- 在《当代文化研究：文学与社会研究的一种途径》（收入1970年《当代批评》）中，霍伽特提出文化研究的基本理论向度：**从高级文学和低级文学（大众文学）的社会道德含义中解脱出来**——不仅评价语言的大众文艺（广告、电影、流行音乐），也关注其他现代传媒，反对在好的文学和坏的文学间作非此即彼的选择。
- **"品质阅读"与"价值阅读"**：仅仅从语言角度进行的文学阅读称"品质阅读"（抑制新批评形式主义砍断文学与社会联系的偏失）；将文学放在更大文化背景中阅读、表述其文化意义的称"价值阅读"。
- 强调作品的三重背景：**审美因素、心理因素、文化因素**——前两者在某种程度上取决于最后的文化特征。价值阅读表明文学是一种文化中的意义载体，是有助于再现、表征文化信仰的对象物。
- 重视大众艺术与"中等低级"的世俗艺术：它们并未完全放弃负载的文化意义，广告和电视同样具有文化层面的意义，应纳入文化研究视野。

### 文化研究的三个"转向"

1. 从**经典文化转向大众文化**的研究，或从中心转向边缘；
2. 从**文字载体**的文化研究转向**影视、图像**的现代文化研究——广告、绘画、建筑、影视、大众传媒、消费文化成为热门话题；
3. 从**纯文学研究**转向种族、性别、阶级、民族性、差异性、社区文化、媒介文化、女性文化和后殖民文化等问题的审理。

文化研究以多元杂糅的方法论研究跨世纪、跨学科、跨地域的文化，在文本与社会、上层建筑与经济基础之间形成有机联系，使中心文化和边缘文化、雅文化和俗文化整合成"统一的文化模式"。@最新文论教程 特别指出：在当代文化研究上做出最重要贡献的是两位法国思想家——[[figures/布迪厄]]和[[figures/博德里亚]]。

## 三、布迪厄：文化研究的当代拓展

[[figures/布迪厄]]（Pierre Bourdieu, 1930-2002）横跨人类学、社会学、教育学、语言学、哲学、政治学、史学、美学文学诸学科，其文化社会理论建立在三块基石上：**场域、习性、资本**。

### 理论风格

- 从"普遍的文化理论"反思推进到"文化实践理论"，超越主观论与客观论、社会物理学与社会现象学、个人与社会的二元对立，拒斥"宏大理论"。
- 倡导方法论上的多元论，将实践向度恢复为知识对象，把概念当作帮助解决问题的实用工具。
- 强调知识分子独立于世俗权力、经济和政治权威，以集体性知识者身份对抗**符号权力**；反对哲学美学化倾向和后现代非理性主义。

### 场域理论

- 社会科学的真正对象不是单纯个体，而是**场域**（field）——一个网络、一个不断建构的结构，其中存在占有者、行动者和体制性的多重权力结构。
- 整个场域可分为艺术场、宗教场、经济场、学术场、法律场等；每个场域是具有不同规则的"游戏圈"，又是一种资本的垄断（艺术场域垄断文化权威，科学场垄断科学权威）。
- 所有场域都包含在**权力场**之内：艺术场往往被占统治地位的权力场控制，文学知识分子是"统治阶级中被统治的那部分人"。

### 习性（habitus）

- 习性是在社会化个人境遇中逐渐习得的"**第二天性**"，是一种结构塑形机制（structuring mechanism）：既不完全是个人性的，又生成而非一成不变。
- 习性与"习惯"不同：习惯是外部使主体获得的适应性，习性则具有能动性、生成性、建构性。
- 场域构造习性，习性体现场域的内在必要性；习性是"在个体之上体现出来的社会化了的主体性"——如果说场域是无形话语权，习性就是与个体紧密相关的小型话语权。

### 文化资本与象征资本

布迪厄受马克思影响，将资本分为**经济资本、文化资本、社会资本、符号（象征）资本**（参见 [[concepts/文化资本]]）：

- **文化资本**以受教育资格的形式被制度化，以精神和身体持久性情的形式存在（具体状态）、以文化商品形式呈现（客观状态）、以学术资格形式出现（体制化状态）。其传递比经济资本更具隐蔽性，"文化资本的传递成了资本继承性传递最佳的隐蔽形式"。
- **象征资本**是被人们承认接受了的政治、经济、社会、文化资本，是一个"话语暴力系统"——将客观等级制度、权力关系再现成合法性、合理性的社会理想秩序。
- 教育是一种**象征符号暴力**手段，从事社会的再生产；文化资本拥有者可以支配文化资本少的群落。在国际地缘文化中，文化弱势的"国家—民族"因文化资本匮乏而屈居世界中心话语边缘。
- **社会资本**是为社会团体所认可的集体性资本，即社会声望、知名度及占有文化象征和经济资本的程度。

### 反思性社会学与身体视域

- 反思性的对象不是个别学者，而是**一个群体、一个场域**；反思性主体是作为整体的社会科学场域，反思对象是整个人类存在的生存空间。
- 反制度性、"主体之死"（作为个体的孤独主体的死亡）、学术人处境的自我对象化、屈服与反抗的辩证法。
- **身体是一种资本**：身体的发展与其社会地位不可分割，对身体的运用、塑形显示身体背后的权力压迫和文化资本的隐蔽存在；身体资本可转化为经济资本和文化资本。经济资本与身体形态、吃、喝、广告及大众文化无不与身体紧密相关，这正是当今"文化研究"的关注点。
- 《自由交流》中的艺术观：真正的艺术家必须秉有孤独独立的意识和独立的价值判断；文化资助是一种微妙的统治形式，文化研究应该"揭底"，揭穿文化领域中不知不觉的支配与被支配关系。

### 意义与局限

布迪厄以反思性思路开辟独特的社会理论和批评之路，有助于第三世界边缘文化知识分子对知识生产、文化资本加以深切反思。局限在于：建构共识性社会图景而缺乏具体历史语境（结构功能主义的普遍性错误）；过分注重日常性哲学、拒斥宏观社会转型研究，可能导致"微观一元论和日常话语独断论"；微观文化分析中忽略了跨文化语境的宏观文化冲突分析。

## 四、博德里亚：消费文化理论

[[figures/博德里亚]]（Jean Baudrillard, 1929-2007）从后现代消费社会理论角度透视当代世界，关注现代性问题与文化危机、消费社会形态转型、媒介传播结构、消费主义与日常生活、商品拜物教中的精神生态危机、大众传媒与世俗化问题。

### 现代性问题与"完美的罪行"

- 《消费社会》《生产之镜》《拟像与模拟》之后，《完美的罪行》进一步研究现代性传媒和技术问题："完美的罪行就是创造一个无缺陷的世界并不留痕迹地离开这个世界的罪行。"
- 当代人容易将虚拟事物看成现实存在、将心造幻影当成现实；屏幕与影像激增造成幻觉破灭的幻觉。
- 人类正处于新的**类像时代**：计算机信息处理、媒体和自动控制系统，以及按照类像符码和模型形成的社会组织，已**取代生产的地位而成为社会的组织原则**。后现代商品价值不再取决于满足需要或交换价值，而取决于交换体系中作为文化功能的**符码**。

### 消费社会的特征

1. **以最大限度攫取财富为目的**，不断为大众制造新的欲望需要；"据为己有"成为"丰盛社会"的个体原则。
2. **消费意识转化**：超前消费和一掷千金成为时代精神表征；消费构成获得身份的商品符码体系和[[concepts/符号消费]]过程；广告轰炸诱导人加入物质饕餮大军。
3. **日常生活精神颓败**：人日益成为"物"，成为官能性物质性的人；大众交流获得的不是现实而是对现实产生的眩晕；生活日常性演变为挫折感和犬儒主义。
4. **浪费式消费成为日常义务**："在这个社会中，浪费式消费已变成一种日常义务，一种类似于间接赋税的通常无形的强制性指令。"
5. **广告的虚假幸福与民主承诺**：广告通过躯体欲望和消费需要的生产调动人们的内在欲望；"广告既不让人去理解，也不让人去学习，而是让人去希望，在此意义上，它是一种预言性话语"；消费面前的形式民主掩盖了深刻的真实不平等。
6. **人造物质丰富与自然权力匮乏**：过去无需花钱唾手可得的财富（纯净空气、绿色、水、宁静）变成唯有特要者才能享用的奢侈品；"物质的增长……意味着在需求增长与生产力增长之间这种不平衡本身的增长，'心理的贫困化'产生于此"。

### 商品拜物教中的精神生态危机

- **城市异化与人的片断化**："消费是一个系统，它维护着符号秩序和组织完整：因此它既是一种道德（一种理想价值体系），也是一种沟通体系、一种交换结构。"
- **文化消费与"媚俗"**：媚俗提出"模拟美学"——失去原作精神的滑稽模仿，功能是"表达阶级的社会预期和愿望以及对具有高等阶级形式、风尚和符号的某种文化的虚幻参与"；消费逻辑取消了艺术表现的传统崇高地位。
- **电视播撒与消费心理模式**：媒体让我们看到的世界以牺牲世界丰富性为代价，人成为媒体的附属或延伸；电视将不同人的思想、体验、价值认同"整流"为同一频道、同一观念模式；大众传播的单向度是"无回应"缺乏反馈的话语输出；私人空间公众化与世界"类像"家庭化导致传媒全球化。
- **身体策略与生命自恋**：身体变成"救赎物品"，"在这一心理和意识形态功能中它彻底取代了灵魂"；消费中进行集体性的身体"指导性自恋"，休闲成为"对时间的消费"。

### 白色社会、类像与后现代镜像

- 博德里亚称消费社会为"**白色社会**"：没有感情介入、没有形而上冲动、也不可能再有异端邪说，充斥着预防性白色的饱和，没有眩晕没有历史深度，除物质神话外无其他精神话语立足。
- 关键词：**类像（simulacrum）、内爆（implosion）、超真实（hyperreality）**——不断复制传播的、内爆的、虚假的类像使政治经济文化消失界限，现实与类像彼此不分。
- 理论局限：过分强调技术中心主义，取消现实的第一性问题，将观念对现实的折射过分夸大；"跟着欲望走"使消费主义在个体狭窄空间播撒非主体意识；"致命的策略"将逻辑推导极限使其走向自身反面——"博德里亚已经面对后现代传媒社会的病灶却无力开出药方"。
- 当代意义：对商品拜物教的分析超越了霍克海默和阿多诺的西马分析模式，采用后现代式话语权力分析；提供了阐释后现代社会镜像的新视角；对第三世界（包括当代中国）的消费主义思潮和媒体膨胀具有"他者的警示"作用。

## 五、汤姆林森：文化帝国主义研究

[[figures/汤姆林森]]（John Tomlinson, 1949- ）所著《文化帝国主义》（1991）运用福柯"话语分析"方法，展示西方近20年彼此对立的文化帝国主义讨论，确立**四个基本维度**（参见 [[concepts/文化帝国主义]]）：

| 话语维度 | 汤姆林森的辨析 | @最新文论教程 的批评 |
|---|---|---|
| **媒介帝国主义**话语 | 媒介不是现代文化的中心，文化帝国主义是宽阔的文化变迁过程，媒介只是众多运作要素之一；认为媒介中性、平等传播而非"强加意识形态" | 媒介全盘进入文化域后已变成后现代文化经验的原则，以激烈方式改变文化疆界，使异于西方的文化失去"他性"；一种不断灌输的话语是"权力"的方式 |
| **民族国家**话语 | 不同意文化帝国主义是本土文化为外来文化"侵略"的说法，宁用"影响"概念；主张由地理范畴（本土/外国）转为历史范畴（传统/现代） | 自由主义立场否定文化差异性、民族性，单方面强调同一性、全球性，将资本主义"全球化"取代"本土化"的过程"解政治化"；抹杀民族性导致文化表征危机和价值认同危机 |
| **全球资本主义批判**话语 | 资本主义文化的重点是消费的总体化过程与经验的商品化；须区分道德化与批判取向，从传统到现代的事实出发掌握消费文化的重要性 | 为消费主义辩护，忽视消费主义负面效应：消费主义一元性排斥其他生活方式，"文化正在死去，死于过剩的生产中、文字的浩瀚堆积中、数量的疯狂增长中"（昆德拉语） |
| **现代性批判**话语 | 前三种话语都须建立在对现代性讨论的前提之上；现代性并未"失败"，只说明现代性的多种文化形式；但承认资本主义现代性"在科技与经济方面强而有力，但在文化方面却薄弱不堪" | 后现代"全球化"概念取代"帝国主义"一词；全球化是文化帝国主义鼎盛而又因全球化实现而自我消失的过程，将削弱所有民族国家的文化向心力 |

汤姆林森勉强得出的结论是：晚期现代性已然自主化的全球机构与制度必须予以解构，后现代景况是我们的"**文化宿命**"，但人类世界的塑造必须看作随着文化意志而变化。@最新文论教程 评价：其论述较单薄，罗列现象多而中肯剖析少，思潮追溯多而问题意识少；甚至因西方中心立场武断否定文化帝国主义对第三世界的"文化支配"，掩盖"文化殖民""文化霸权"的问题实质——"在反思工具理性时又回到工具理性中，批判历史理性时又重新拥抱历史理性"。

## 本章评价

@最新文论教程 对文化研究的总体定位：

1. **学科性质**：文化研究属于后起学科，却以后来者居上的方式成为当代文化一大景观，以多元杂糅的方法论研究跨世纪、跨学科、跨地域的文化。
2. **与西马的关系**：西方马克思主义的文化批判理论和实践为当代文化研究提供了批判角度和研究视域；文化研究更为中性和客观务实，去掉激情浪漫的言说方式和乌托邦巨型想象，走上折中、整合理性的社会文化研究之路。博德里亚对商品拜物教的分析超越了霍克海默、阿多诺的西马模式。
3. **布迪厄**的场域—习性—资本理论揭示文化权力内部机制及其隐蔽性，但忽略跨文化语境的宏观文化分析。
4. **博德里亚**是"当今消费社会最为清醒的反思批判家"，其消费社会审理进入精神生态层面，但"致命的策略"本身是致命的——面对病灶无力开出药方。
5. **汤姆林森**提供了继续思考讨论的框架，但其西方中心立场削弱了批判力度。
6. **文论转型**：文学研究日益泛化为文化研究，从巨型社会文化意识形态分析转向微型文化消费意识形态分析，"使得当代危机问题有可能得到真实的显露"。
