# 生态批评文论

> 本章对应王岳川《当代西方最新文论教程》第十二章"生态文学与生态批评文论"（pp.484-528），涵盖生态文化的发端及其现实针对性、生态文学的特征与价值取向、生态批评的发展与基本特征、深生态学的理论张力与价值、生态批评对当代文论的意义等内容。

## 一、生态文化的发端及其现实针对性

生态理论的发端与全球化的两个重大危机相关：其一是日益恶化的**自然生态危机**，其二是人类精神痼疾在现代消费社会中的**人文精神生态危机**。两大危机均来源于现代性的恶果。

### 现代性批判

- 现代性只有短短500年，与科技发明和人类殖民紧密相关，短短200年使西方成为世界霸主；但现代性极度膨胀会反过来毁灭人类——自然生态危机、社会生态危机、精神生态危机、文化生态危机并存
- 1972年罗马俱乐部报告《成长的界限》警告：经济过热与人口增长如不遏制，地球及人类将因环境污染和食物不足在100年内毁灭
- **消费主义症候**：消费主义不断制造"疯狂追新"心理，身体在时尚升级而精神在降级；消费主义具有双重欺骗性——允诺幸福的普遍性、设定"消费者自由=自由"的虚假命题，自由被降格为消费
- "制度现代性"使人异化（卓别林《摩登时代》），"审美现代性"以反抗异化为纲领，把"审美"转变为"审丑"——马尔库塞所谓"艺术不再是审美，艺术变成了反抗"；但审丑艺术正走向自己的反面

### 生态理论的发生与发展

- "生态学"（ecology）由希腊语oicos（房子、住所）派生；思想渊源可追溯到18世纪浪漫主义——1858年梭罗《瓦尔登湖》阐释人与自然和谐观念
- 1886年德国动物学家**海克尔**在《生物体普通形态学》中提出："生态学是关于有机体与周围环境关系的全部科学"
- 一般认为1970年在西方兴起的"**生态主义**"（Ecologism）开始了生态文化的艰难历程
- 生态批评发展的三个时期（西蒙·C.埃斯托克说）：
  1. 1978年威廉·鲁克尔曼（William Rueckert）发表《文学与生态学：生态批评的实验》，首次提出"生态批评"术语，未引起重视
  2. 1993年帕特里克·墨菲创办《文学与环境跨学科研究》杂志，标志学派逐渐形成
  3. 1996年格罗特费尔蒂、弗罗姆编《生态批评读本》和劳伦斯·布伊尔《环境的想象》出版，生态批评有了理论纲领和美学原则
- 20世纪60年代以来，生态哲学、生态神学、生态政治学、生态经济学、生态女性主义、生态文学、深生态学等领域雨后春笋般出现，共同特征是"**去掉人类中心主义，坚持自然中心主义**"
- 生态理论反对德里达"文本之外一无所有"的文本中心主义：贝特认为"生态诗学主张我们必须牢牢把握一种可能性，即那种被称为诗歌的文本尺度可以使我们回忆起人类最古老的知识：**没有大地尺度，我们就不复存在**"

## 二、生态文学的特征与价值取向

[[concepts/生态文学]]（ecoliterature）是生态文化的重要组成部分。

### 定义与谱系

- 生态文学以注重**人与自然的和谐**、提倡自然中心主义反对人类中心主义为旨归，以生态思想和生态视角为出发点，将"以自然为本的文学"和"以人为本的文学"相并列
- 布伊尔：生态文学是"**为处于危险的世界写作**"的
- 生态文学主要指那些敏感地对现代世界生态危机加以揭示、对人类中心主义价值观加以批判、对导致生态危机的现代文明加以反省的作品
- **广义生态文学**：具有生态文化意识的传统作品，如梭罗《瓦尔登湖》、华兹华斯《序曲》、哈代威塞克斯系列小说
- **狭义生态文学**：作家有鲜明生态文化立场，直面现代性生态危机，如雷切尔·卡森《海的边缘》《寂静的春天》（生态文学创始人和环境运动推动者）、艾特玛托夫《白轮船》、博伊尔《地球之友》、加藤幸子《都市中的自然》

### 价值取向

- 生态文学不是一般描写自然风光的闲适感，而是从文本中**空前凸显人类的重大困境**，并对危及人类整体未来的困境加以审美解答
- 创作上：注重生态哲学深度思考，探索人在世界中重获"家园"感的新感知方式
- 作品构成上：注重自然中心主义和人与自然和谐，在叙事引导下探索走出全球生态危机的可能性
- 阅读上：通过阅读提升人从自然母体中生存的内在精神世界观，激发热爱生命的天性
- 生态文学的特殊性在于：它是人类与自然从"对抗—征服—报复"恶性循环中走出来、重新摆正位置的诉求在文学形式中的表达
- 教材以海明威《老人与海》为反例：其中人类中心主义表现突出，"人"与"自然"的对立构成故事基线，"美国精神"隐含"人类是万物主宰"的潜在话语，在生态文化时代遭到质疑

## 三、生态批评的发展与基本特征

[[concepts/生态批评]]（ecocriticism）是言人人殊的话语。大多数人认同彻丽尔·格罗特费尔蒂的定义："**生态批评是探讨文学与自然环境之关系的批评**。"

### 学科制度化历程

| 时间 | 事件 |
|---|---|
| 1978 | 鲁克尔曼《文学与生态学：一次生态批评实验》在《衣阿华评论》发表，首次明确"将文学与生态学结合起来" |
| 1992 | "文学与环境研究会"（ASLE）在美国内华达大学成立 |
| 1994 | 克洛伯尔《生态批评：浪漫的想象与生态意识》出版，提倡"生态学的文学批评" |
| 1995 | 科罗拉多大学首次研讨会，论文后结集为《阅读大地：文学与环境研究的新走向》（1998） |
| 1996 | 美国第一本生态批评论文集《生态批评读本》出版（格罗特费尔蒂、弗罗姆主编） |
| 1998 | 英国第一本生态批评论文集《书写环境：生态批评与文学》出版（克里治、塞梅尔斯主编） |
| 1999 | 《新文学史》推出生态批评专号 |
| 2001-2004 | 布伊尔《为危险的世界写作》、洛夫《实用生态批评》、加勒德《生态批评》相继出版 |

格罗特费尔蒂的经典定义："生态批评研究文学与物理环境之间的关系。正如女性主义批评从性别意识视角考察语言和文学，马克思主义批评把生产方式和经济阶级的自觉带进文本阅读，**生态批评运用一种以地球为中心的方法研究文学**。"

### 六大基本特征

1. 以研究文学中的**自然生态和精神生态**问题为主，把握文学与自然环境互涉互动关系
2. 可从生态文化角度重新阐释阅读传统文学经典，从中解读被遮蔽的生态文化意义，重建人与自我、他人、社会、自然、大地的审美关系
3. 对艺术创作中的人的主体性问题保持"政治正确"——既不能有人类中心主义立场，也不能持绝对自然中心主义立场，主张人类由"自我意识"向"**生态意识**"转变
4. 将文学研究与生命科学相联系，具有文学跨学科特性
5. 继承绿色革命意识形态，强调不背离文学精神和文学话语，尽可能在文学文本形式和艺术手法层面展开话语叙事
6. 从生命本质和地球双重视野考察人类过去与未来存在状态，使文学抛弃形式主义文字游戏

布伊尔强调：生态批评通常在环境运动实践精神下开展，是跨学科的——从科学研究、人文地理、发展心理学、社会人类学、哲学、史学、宗教以及性别、种族研究中吸取阐释模型；早期生态批评家强烈反对现代文本性理论，核心任务是强调文学应使读者重新去与自然"接触"。

### 深生态学

"**深生态学**"（Deep ecology）由挪威哲学家奈斯（Arne Naess）1982年首次提出。"深"与"浅"相对，触及现代性弊端最核心问题——科技发展使人在自然面前巨人化。思想地基包括施韦兹和泰勒的"尊重生命"理论、莱奥波德的"大地伦理学"。

两大最重要原则："**自我实现**"与"**建立在生态中心基础上的平等**"。比尔·戴维尔《深生态学》归纳的特质包括：拒斥人类中心主义狂妄、众生平等、认同世界各种生命形式、发展生态乌托邦理想、批判工具理性、强调社会文化实践行动。沃斯特（Donald Worster）认为："我们今天所面临的全球性生态危机，起因不在生态系统自身，而在于我们的**文化系统**。"

## 四、生态批评对当代文论的意义

1. **人类性价值中断与东西方前沿话语整合**：当代价值伦理、审美情趣与传统整体中断，"唯新主义"使人成无根无源之人；生态文化一方面是现代性内部的自我反思，另一方面是东方文化对西方现代性的纠偏——东方思想的绿色和谐、"天人合一"、中庸之道可化解人与他人、人与自己、人与自然的冲突
2. **聆听物种灭绝的警钟**：本世纪以来5400余种动物在人类统治下提前灭绝；人类中心主义虚拟的人类霸权将人与生物链条脱节；生态批评要求削弱贪婪之欲，不为任何冠冕堂皇的目的从事杀戮
3. **对人的生存意义的新导向**：西方出现"慢生活"浪潮（1986年卡罗·皮逊尼发起；慢城市、慢学校）、"极简生活主义"（向东方学做"生命减法"，老子"损之又损，以至于无为"）；返璞归真、"少就是多"（less is more）的简单生活在21世纪将成为普遍风气
4. **精神价值整体创新**：以生态平衡要求人的精神生态平衡，通过生态文化调理避免现代性"异化"制度性断裂的覆辙，寻找人类文化身份的重建之路

教材特别引《阅读大地》编者所言："**具有生态敏感性的文学批评的一个重要作用就在于它具有一种潜能，推动人类全体成员培养起更加深厚的生态人文素养。**"（参见[[concepts/生态敏感性]]）

## 五、批评与局限

达纳·菲利普斯在《生态论的真相》中对生态批评提出异议：认为生态批评是"旧瓶装新酒"，理论上没有什么创新而是用时髦术语哗众取宠；生态批评仍未形成自洽的理论体系，理论根据匮乏使其只不过成为情感的叙述话语；想当然地把相当复杂的进化论及生态理论纳入文学批评而难以消化。

但教材坚持：生态批评在西方文论的"文本喧哗""话语游戏"中走出来，开始俯身生养死葬的大地，直面并关心人类存在的真实困境，这是不可否定的事实。

## 本章评价

@最新文论教程 对生态批评文论的总体判断：

1. 生态文化和生态批评不是普通的关于人与环境的文学研究，而是属于文化研究大范围中的新拓展理论领域，标志西方文论进入"理论生产缓慢期"后的新审美视角
2. 生态理论是一种**直面人类现实处境的实践理论**，与其他西方文论突显形而上思辨不同，它走出"语言的牢笼"，关注时代困境
3. 生态批评将"文学性"与"生态性"整合，对人类未来充满希望，拒斥"对未来的绝望"，显示出乐观主义精神特质
4. 东方思想（绿色和谐、辩证思想、综合模糊思想、"仁者爱人"）是生态文化的重要思想资源，新世纪东西方对话将生出新世界蓝图
