# 朱立元《当代西方文艺理论》3.3.2 文学性：诗性功能

> 来源：[[@朱立元#ch3.3.2]]，原书第 58-59 页。

## 章节主旨

阐述[[figures/雅各布森]]如何从语言学角度阐释[[concepts/文学性]]：将诗界定为具有独立价值的词的形式显现，提出著名的语言六要素六功能说，将[[concepts/诗性功能]]界定为言语突出指向自身时的功能，并以隐喻/转喻两极分析法探索诗的内在结构。

## 核心内容

### 文学性存在于语言形式之中

雅各布森指出文学性存在于文学作品的语言形式之中。他从分析诗歌语言入手，把诗歌放置在语言的交际环境中加以探讨，试图从语言功能上阐释文学性，说明诗歌语言的特征。

### 诗的本质：词的形式显现

雅各布森以类比方式界定诗的本质：

- 造型艺术是具有独立价值的视觉表现材料的形式显现
- 音乐是具有独立价值的音响材料的形式显现
- 舞蹈是具有独立价值的动作材料的形式显现
- **诗便是具有独立价值的词的形式显现**

诗的本质不在指称、叙述外在世界的事物，而在具有表达目的的诗歌语言（词）的形式显现。

### 诗的功能：符号与指称不能合一

> "诗的功能在于指出符号和指称不能合一"

即诗歌（文学）语言往往打破符号与指称的稳固的逻辑联系，而为能指与所指的其他新的关系和功能（如审美）的实现提供可能。

**"一部诗作应该界定为其美学功能是它的主导的一种文字信息"**——诗歌语言虽有提供信息的功能，但应以"自指"的审美功能为主。

### 语言六要素与六功能说

在美国期间，雅各布森发表《结束语：语言学和诗学》，提出任何言语交际都包含六个要素：

| 要素 | 对应功能 |
|---|---|
| 说话者 | 情感功能 |
| 受话者 | 意动功能 |
| 语境 | 指称功能 |
| 信息 | **诗性功能（审美）** |
| 接触 | 交际功能 |
| 代码 | 元语言功能 |

- 侧重于语境→指称功能
- 侧重于说话者→情感功能
- 侧重于受话者→意动功能
- 侧重于接触→交际功能
- 侧重于代码→元语言功能
- **只有言语交际侧重于信息本身，诗的功能（审美）才占主导地位**

"信息"指言语本身，当言语突出指向自身时，其[[concepts/诗性功能]]才突现出来，其他实用功能才降到最低限度。

### 隐喻与转喻的两极

雅各布森在《隐喻和转喻的两极》一文中把诗歌分为两类：

- **转喻类**：一般的现实主义作品中转喻结构居支配地位，注重情节的叙述、环境的描写，通过转喻表现人物与环境的关系，主要指向环境；如罗斯的英雄史诗中转喻方式占优势
- **隐喻类**：浪漫主义作品以隐喻为主导，很少通过清楚地描写与事物的外在具体特征来直接表述某种意义，而是把要表述的意义隐含在诗的字里行间，让读者自己去品味；如俄国的抒情诗

**在隐喻类的文学作品中，诗性功能强，因而文学性也就较强。**

### 诗性功能的结构分析

雅各布森以[[figures/索绪尔]]语言学为依据，把语句的构成放在**选择**和**组合**这两根纵横交错的轴上加以分析：

- **选择轴**：近似于索绪尔语言学的纵组合概念，即语句中排列的词是从众多能够替换的对等词语中选择出来的
- **组合轴**：基本等于索绪尔语言学的横组合概念，即上下文之间的联系

**诗性功能就是要把对等原则由选择轴引到组合轴，形成诗句的对偶。**（若用中国文学的话来说，就是对仗。）

雅各布森努力寻找发音和意义上对应、语法功能相同的词语，寻找由一行对称诗句组合而成的诗节，并由此发掘诗的内在结构。

### 评价

雅各布森在诗学理论上的独特贡献是显而易见的，**他的研究为后来[[movements/结构主义]]诗论的发展奠定了基础。**
