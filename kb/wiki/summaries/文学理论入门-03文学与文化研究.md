# 文学理论入门 第 3 章 文学与文化研究

> 来源：[[@文学理论入门#ch3]]，原书第 43-57 页。

## 章节主旨

卡勒梳理"文化研究"（cultural studies）作为一种理论思潮的兴起、它与文学研究的关系、以及在英美两国的不同形态。本章核心论点是：**文学与文化研究的关系**争论充满对精英统治的抱怨和对通俗文化带来"灭顶之灾"的指责，但两组问题应区别开——研究一种或另一种文化对象的价值问题、研究各类文化对象的方法问题。卡勒主张"激进的文化研究与被动的文学研究相对立也许只是一个空想"。

## 一、文化研究的兴起背景

### "文化"概念的双重含义

雷蒙德·威廉斯（Raymond Williams）在《文化与社会》（1958）中列出"文化"的现代含义：
1. 心灵的普遍状态或"习惯"
2. 整个社会中知识发展的普遍状态
3. 各种艺术
4. 物质、智识、精神能力的整体

→ 第四种人类学含义（"整体生活方式"）在文化研究中被采纳，文化研究着眼于人类生活的文化层面。

### 文学与文化研究的张力的两种"文学性"传统

- **文学作为文化精英的活动**——研究文学 = 研究文化中最精致的部分
- **文学作为文化的"再现"或"表象"**——研究文学 = 研究特定时代文化的表象

文化研究倾向于**第二种**：把文学作品作为文化史或文化分析的文献来对待。

## 二、文化研究的关键议题

### 文化研究的四个来源

文化研究有四个主要源头（@文学理论入门#ch3 中提到）：
1. **文学研究的文化化**——把文学研究扩大为文化研究
2. **马克思主义文化理论**——[[figures/葛兰西]]的"文化霸权"理论：主权即一种由被控制者接受的统治格局。统治集团不是纯粹以力量去统治，而是通过一种协调的社会结构，文化正是这种结构中的一部分，它使当今的社会组合法化
3. **法国结构主义**——阿尔都塞"意识形态与意识形态国家机器"
4. **英国文化研究传统**——伯明翰学派

### 文化研究与文学研究的区别

卡勒指出：文学研究和文化研究的目的不同。从事文化研究的人常常希望**当代文化的研究能够成为一种对文化的介入**，而不仅仅是一种描述。《文化研究》的编辑们说："文化研究因此而相信它自己的知识成果是应该，而且能够，创造变化的。"

## 三、英美文化研究的差异

### 英国：政治性的反抗

- 在六七十年代的英国，研究工人阶级的文化有**政治内涵**
- 英国是民族文化特征与高雅文化丰碑连在一起的国家（莎士比亚、英国文学传统）
- 研究通俗文化本身就是**一种反抗的行为**

### 美国：跨学科学术领域

- 美国是一个常常用反对高雅文化来解释其民族特点的国家
- 马克·吐温《哈克贝利·芬》以哈克·芬为躲避萨莉姨妈对他的"文明开化"出逃为结尾——"美国人传统上就是逃离文化的人"
- 在美国，回避高雅文化而研究通俗文化**算不上政治的激进，也算不上反抗的姿态**，倒更能称得上是一门大众文化学科
- 美国的文化研究与激励文化研究的政治运动很少有关联，倒是可看作一个信息资料丰富的、跨学科的领域

## 四、两组问题的区分

面对文学与文化研究关系的喧嚣争吵，卡勒主张区别两组问题：

### 第一组：研究一种或另一种文化对象的价值问题

- 研究莎士比亚而不是肥皂剧的价值已经不再是想当然的，而是需要论证的
- 比如在知识和道德观的培养方面，不同种类的研究能够取得什么不同的结果？
- **德国纳粹集中营的指挥者们有的也是文学、艺术、音乐的鉴赏家**——这就使"某一类研究能取得什么结果"的问题变得复杂

### 第二组：研究各类文化对象的方法问题

- 是把文化对象作为错综的结构去解释，还是把它当作社会同一性的表象来解读？
- 鉴赏性的解释一直与文学研究联系在一起
- 表象分析的方法与文化研究联系在一起
- **但这两种方法对于两种文化对象也都是适用的**——仔细解读非文学作品并不意味着要对它做出美学的评价，对文学作品提出文化方面的问题也不说明这部作品就只是一份记录文件

## 五、文化研究的"激进"性

卡勒的清醒判断：
- 要使激进的文化研究与被动的文学研究相对立也许只是**一个空想**
- 文化研究"应该是"激进的——但"应该"两字本身就表明它并不认为自己的成果将会创造变化，"如果那样讲，就无异于自吹，更不用说有多么幼稚可笑了"
