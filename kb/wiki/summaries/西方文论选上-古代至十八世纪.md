# 西方文论选（上卷）——古代至十八世纪

## 基本信息

- **主编**：伍蠡甫
- **出版**：人民文学出版社，1964年
- **范围**：上卷自古代至十八世纪
- **体例**：以时代、流派为经，国别、作家为纬；作家以生年先后为序

## 选文篇目

### 1. 古希腊文论
- **亚里士多德《诗学》选段**：占大量篇幅，涉及摹仿论、悲剧定义、情节安排、性格塑造、悲剧布局等
  - 摹仿对象（02）、摹仿方式（03）、诗的形而上学（04）、悲剧定义（06）、事件安排（07）、布局与喜剧布局（10）、性格（05/15/13）、诗的定义起源和作用（07/14）、史诗情节（10）、史诗与悲剧比较（11）、反驳诗人（12）
- 关联：[[figures/亚里士多德]]（待生成）、[[concepts/摹仿-mimesis]]（待生成）、[[concepts/净化-catharsis]]（待生成）

### 2. 古罗马/文艺复兴文论
- **贺拉斯《诗艺》选段**：风格准确性（05-语言的推确性）
- **锡德尼**选段：诗人为"_maker"（01-我对于繪画的古怪想法）
- **维柯**选段：各民族语言起源（01-各民族在还未开口説的时代）

### 3. 新古典主义文论
- **布瓦洛**相关选段
- **关于趣剧/兴趣/表情**等新古典主义话题

### 4. 其他选段
- 但丁《论俗语》（19-现在我們宣布这种俗语）
- 画论（繪画、音乐、文学的关系）
- 塞万提斯《堂吉诃德》相关（29-叙述堂吉德...着魔的奇迹）
- 主教覆士书（30）
