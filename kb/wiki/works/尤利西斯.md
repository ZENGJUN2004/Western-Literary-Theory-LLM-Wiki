# 尤利西斯（Ulysses, 1922）

## 基本信息

- **作者**：[[figures/乔伊斯]]（James Joyce, 1882-1941）
- **成书年代**：1922 年（由 Sylvia Beach 在巴黎出版）
- **语种**：英语
- **学术地位**：意识流小说巅峰之作，20世纪最重要英语小说之一，现代主义文学里程碑

## 概述

《尤利西斯》是乔伊斯最具代表性的意识流小说，以1904年6月16日这一天都柏林的日常生活为题材，通过利奥波德·布卢姆（Leopold Bloom）、斯蒂芬·迪达勒斯（Stephen Dedalus）和摩莉·布卢姆（Molly Bloom）三人的意识流动，编织出一部现代人精神的"日常史诗"。

小说标题直接呼应荷马史诗《奥德赛》——乔伊斯在书中设置了与《奥德赛》相对应的18个章节结构，被称为"神话方法"（mythical method）的典范。

## 核心特点

### 一、意识流的巅峰实验

《尤利西斯》将[[concepts/意识流]]叙事推向极致，不同章节采用不同的意识流技巧：

| 章节 | 意识流技巧 | 说明 |
|---|---|---|
|  TELEMACUS（ telemachus） | 第三人称限制视角 | 斯蒂芬的哲学沉思 |
| CALYPSO（卡吕普索） | 自由间接引语 | 布卢姆的日常活动与内心思绪交织 |
| LOTUS EATERS（荷马食莲人） | 意识流独白 | 摩莉的丈夫与情人的心理刻画 |
| SHEEP'S EYE（斯库拉与夏律狄丝） | 意识流独白 | 布卢姆观看广告员巴克的故事 |
| CIRCE（喀耳刻） | 梦幻剧形式 | 所有人物的潜意识欲望在剧中爆发 |
| EUREKA（eeaureka） | 无标点意识流 | 摩莉的全篇意识流独白，6部曲 |
| ITHACA（伊萨卡） | 科学问答体 | 布卢姆与斯蒂芬的对话以 catechism 形式呈现 |
| PENELope（佩涅洛佩） | 无标点意识流 | 摩莉的内心独白，约40分钟不间断 |

### 二、神话方法

[[figures/艾略特]]在《尤利西斯：秩序与神话》（1923）中提出"神话方法"概念：乔伊斯通过荷马史诗的结构框架，为现代都市生活的混乱赋予形式和意义。神话不是装饰，而是理解现代经验的方法论工具。

### 三、语言实验

《尤利西斯》的语言实验包括：
- 多语混用（英语、爱尔兰语、拉丁语、希腊语、意大利语等）
- 文体风格的不断变换（新闻体、戏剧体、科学问答体、意识流独白等）
- 大量双关语、谐音词和文字游戏
- 终章摩莉独白采用无标点、57句的超长意识流

## 在文论史中的地位

《尤利西斯》在文学理论史上的意义在于：

1. **意识流方法的极限**：展示了[[concepts/意识流]]叙事的可塑性边界
2. **现代主义的经典文本**：被视为现代主义文学的最高成就
3. **解构主义的资源**：德里达等解构主义者从本书的语言游戏中发现了"延异"的文学实践
4. **精神分析批评的文本**：布卢姆的俄狄浦斯情结、摩莉的多重欲望等成为精神分析批评的经典案例
5. **后现代主义的先声**：《尤利西斯》的语言实验预示了后现代主义的文本观念
