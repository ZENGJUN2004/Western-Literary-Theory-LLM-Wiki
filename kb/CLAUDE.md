# 西方文论知识库

这是一个由 LLM 维护的双层 markdown 知识库，语料来源是 `../` 目录下的 20 余本西方文论教材（中文教材 + 英文原典）。所有内容都是纯文本 markdown，可用任何编辑器打开；推荐用 Obsidian 把本目录作为 Vault 打开，获得 `[[wiki-link]]` 双向链接与图谱视图（可选）。

**会话启动**：每次新会话开始时，先读 `wiki/_log.md` 了解最近操作历史，建立上下文连续性；若目录还不存在则跳过。

## 架构

```
kb/
├── raw/                          # 不可变教材原文（LLM 只读）
│   ├── <教材简称>/               # 一本教材一个子目录
│   │   ├── 01-古希腊罗马文论.md  # 按章节切片
│   │   ├── 02-中世纪文论.md
│   │   └── _meta.md              # 教材元信息（书名/编者/出版社/年份/语种）
│   └── assets/                   # 教材原图（人物像、关系图）
│       └── <教材简称>/
│           └── NN-描述.{png,jpg}
├── wiki/                         # LLM 完全拥有的派生层（人类只读）
│   ├── summaries/                # 每章一个摘要（1:1 对应 raw 章节）
│   ├── figures/                  # 文论家人物页（柏拉图、巴赫金、海德格尔…）
│   ├── movements/                # 流派页（古典主义、新批评、结构主义…）
│   ├── works/                    # 文论原典页（《诗学》《拉奥孔》《文学理论》…）
│   ├── concepts/                 # 概念/术语页（模仿、复调、互文性、陌生化…）
│   ├── comparisons/              # A vs B 对比 + 跨教材叙述对照
│   ├── overviews/                # 主题综述（≥3 篇相关章节时生成）
│   ├── synthesis/                # 查询归档的综合分析
│   ├── _index.md                 # 自动维护的总索引
│   └── _log.md                   # 操作日志（append-only）
└── CLAUDE.md                     # 本文件
```

**两层意义**：`raw/` 是不可变的事实底座——教材原文。`wiki/` 是 LLM 对教材的当前理解。理解可随时重新生成，原文永远保留。

**两个特殊文件**：
- `_index.md`：内容导向的目录。查询时**首先读 index** 定位相关页面。
- `_log.md`：时间线导向的操作记录，append-only。新会话通过读 log 了解最近发生了什么。

## 原则

1. **raw 不可变**：raw 文件及其附件写入后绝不修改、绝不删除
2. **wiki 可重生**：summaries → figures/movements/works/concepts → comparisons → overviews 都可从 raw 重新生成（synthesis 除外）
3. **先查后建**：创建任何页面前，搜索已有文件和别名，避免重复
4. **信息不丢失**：增量更新时保留所有已有信息
5. **链接格式**：始终使用 `[[folder/name]]` 格式（如 `[[figures/柏拉图]]`、`[[concepts/复调]]`），带文件夹前缀
6. **语言**：wiki 内容默认中文；术语保留英文原名（首次出现写作"中文译名（English Term）"），人物首现写"中文译名（Original Name, 生卒年）"
7. **教材可追溯**：所有论断必须可回溯到 raw 中的某本教材某章节，引用格式 `[[@朱立元#ch3]]`（@教材简称#章节号）

### 章节切片约定

- raw 文件命名：`<教材简称>/<NN>-<章节标题>.md`，NN 为两位零填充章节序号（`01`、`02`…）
- 章节标题识别优先级：`第X章` > `Chapter X` > `X.` > 数字+点号 > 一级标题样式
- frontmatter 必填字段：`book`、`chapter`、`pages`、`lang`

最小 frontmatter 模板：

```yaml
---
type: raw-chapter                # raw 层固定此值
book: @朱立元                    # 教材简称
chapter: 3                       # 章节号（与文件名 NN 一致）
chapter_title: 精神分析批评
pages: 45-78                     # 起止页码
lang: zh                          # zh / en
ocr_cleaned: true                # 是否做过 OCR 重影清洗
ingested_at: 2026-09-03
---
```

### wiki 页面 frontmatter

```yaml
---
type: figure | movement | work | concept | comparison | overview | synthesis
created: YYYY-MM-DD
updated: YYYY-MM-DD
tags: [tag1, tag2]
aliases: [别名1, 别名2]            # 仅 figure/concept/movement 有
sources:                          # 该页面信息来源的章节列表
  - "[[raw/朱立元/03-精神分析批评]]"
  - "[[raw/马新国/05-精神分析]]"
---
```

## 工作流

### 摄入（已切片的 raw 章节就绪后）

用户说"摄入 @朱立元 第 3 章"或"ingest @朱立元 ch3"时，执行三阶段：

**阶段 1：确认 raw 就绪**
1. 读取 `raw/朱立元/03-精神分析批评.md`，确认 frontmatter 完整
2. 在 `wiki/_log.md` 检查是否已摄入过，已摄入则跳过或重新编译

**阶段 2：编译 wiki**
1. **摘要**：在 `wiki/summaries/` 创建 1:1 摘要，链接回 `[[raw/朱立元/03-...]]`
2. **人物抽取**：识别该章涉及的文论家
   - 已有 `figures/<人物>.md` → 增量更新（保留已有信息，追加新来源到 sources，补充跨教材叙述对照表）
   - 不存在 → 新建 `figures/<人物>.md`，按模板填充
3. **流派抽取**：识别该章讨论的流派 → 同上更新 `movements/`
4. **作品抽取**：识别该章引用的文论原典 → 同上更新 `works/`
5. **概念抽取**：识别该章阐述的概念/术语 → 同上更新 `concepts/`
6. **对比评估**：
   - 若该章明显对比两个人物/流派/概念 → 生成 `wiki/comparisons/A vs B.md`
   - 若该章对某概念的表述与已有教材章节差异显著 → 在该概念页的"跨教材叙述对照"表追加一行
7. **综述评估**：若某主题下已有 ≥3 篇相关摘要，生成或更新 `wiki/overviews/<Topic>.md`

**阶段 3：索引与日志**
1. 更新 `wiki/_index.md`（按类型分组列出新增/更新的页面，附一句话描述）
2. append 到 `wiki/_log.md`：时间戳、教材简称、章节号、生成/更新了哪些页面

### 查询（用户提问时）

用户提问时主动搜索知识库回答：

1. **先读索引**：读 `wiki/_index.md` 定位相关页面
2. **定向阅读**：读索引中识别出的相关页面（summaries、figures、movements、concepts 等）
3. **补充搜索**：索引不足时用 Grep 按关键词在 `wiki/` 中补充搜索
4. **综合回答**：内联引用 `[[folder/name]]` wiki-link；引用原文用 `[[@教材#chX]]` 标注来源
5. 知识库中没有相关内容时直接告知用户，不要编造
6. 要有批判性精神，对观点有深度见解，不需要讨好用户

**归档判断**——回答完成后评估是否归档到 `wiki/synthesis/`：

- 综合了 ≥2 个 wiki 页面 → 建议归档
- 产生了跨教材/跨流派的新洞察 → 建议归档
- 用户明确表示有价值 → 归档
- 简单事实查询、单一页面检索 → 不归档

建议方式："这个回答综合了多个来源，要归档到知识库吗？"用户确认后保存为 markdown，更新 `_index.md`，在 `_log.md` append 记录。

### Lint（定期健康检查）

用户说"lint wiki"、"检查知识库"时执行：

**Step 1：结构扫描**（机械化）
1. 缺失页面：Grep 所有 `[[...]]` 链接，检查目标文件是否存在
2. 孤立页面：Grep 每个 wiki 页面的文件名，确认至少被一个其他页面引用
3. 缺失交叉引用：检查同一来源章节中共同出现的人物/流派/概念是否在相关页面被互相引用

**Step 2：内容审查**
4. 矛盾检测：同一人物/概念在不同教材中的描述差异是否被标注在"跨教材叙述对照"表
5. 译名一致性：同一人物/概念在不同教材中的译名差异是否记录在 aliases
6. 缺失页面：被多本教材提及但没有独立页面的人物/流派/概念

**Step 3：发展建议**
7. 数据空白：基于现有知识图谱，建议哪些主题可以补充新教材
8. 新问题：基于已有内容，建议值得探索的新研究方向

输出问题清单 + 建议修复操作，等用户确认后执行。在 `_log.md` append lint 记录。

### 维护

- **重新编译**：用户说"重新编译 wiki"时，从 raw 重新生成所有 wiki 页面（synthesis 保留）
- **更新索引**：用户说"更新索引"时，重新生成 `wiki/_index.md`
- **去重**：摄入前检查章节是否已收录

## 术语与译名规范

- **首次出现**：中文译名（English Term），如"复调（dialogism）"、"陌生化（defamiliarization）"
- **后续引用**：可只用中文译名
- **人物首现**：中文译名（Original Name, 生卒年），如"巴赫金（Mikhail Bakhtin, 1895-1975）"
- **歧义术语**：同一英文术语在不同流派有不同中译时，在概念页 aliases 列出所有译名并标注流派归属
- **原文引用**：英文原典段落保留原文 + 中译；中文教材段落直接引用，注明 `[[@教材#chX]]`
